# キーボード強化（rc.18-dev）

- 変換状態: Mozc の文節・候補 ID を維持し、独立した文節操作バーで前後移動・縮小・拡大を実行する。AI 全文候補は明示的に選ぶ。
- 再変換: ツールメニューの「確定を戻す」は Mozc の UNDO を使う。直前の確定が対象で、他アプリの編集履歴は戻さない。
- AI 負荷: 入力後 600ms の待機、古い結果の破棄、低優先度ワーカーに加え、読みと文脈が一致する結果を最大32件メモリ内で再利用。学習版の更新・無効化で消去する。
- 誤入力補正: 既存の隣接キー・重複入力・濁点／小文字補正を継続。アプリ別プロファイルから補正の可否を選ぶ。
- 学習管理: 候補長押しの履歴削除・優先指定、優先表記一覧からの解除、TTT 専用リセット。TTT の単語別削除は対象外。
- 編集: ツールメニューからカーソル・範囲選択パネルを開き、単語移動・行頭末尾・選択・コピー等を操作する。
- メニュー: 展開時に文字キーを隠す。通常メニューは高さ180dpの3列タイル。編集から上部への表示・非表示を切り替え、タイルを長押ししてドラッグで順序を変更できる。上部には先頭5件まで表示する。
- アプリ別設定: 既存の方式・高さ・片手・機密モードに、AI と入力補正の許可を追加。
- 性能診断: 学習設定から有効化。キー処理・AI の回数、平均、最大時間だけを端末内に保存。本文・文脈・アプリ名は保存しない。
- Beam: 既存の送信内容表示と受信完了表示を継続。受信通信エラー後に受信を再試行できる。

実機での操作・性能・NFC 通信の確認は別途必要。

## rc.25-dev の入力操作

- 定型文: メニューの「定型文」から明示的に挿入。設定から追加・編集・削除でき、最大100件、各2000文字。Keystoreの既存暗号化ストアを使用し、機密モードでは表示・挿入しない。新しいバックアップ対象には含めない。
- カーソル: スペース長押しで左右ドラッグを開始。長押し開始時に振動・表示で通知し、離したときの余計なスペース・変換を抑制。変換中は文節移動、未変換中は読みの編集、確定後は入力先のカーソルを動かす。
- 文節操作: 48dpの文節一覧をタップして対象を選択。「前の文節／次の文節」と「縮める／広げる」を分離。端の文節では不要な前後移動ボタンを無効化。スペースの短い左右フリックは1回だけ境界変更し、押し続けによる連続変更を行わない。
- 安定性: Mozcの編集中にカーソル操作が失敗しても入力先の通常カーソル操作へ流さない。JNI応答が失われた場合は既存の復旧処理を使用。確定後のカーソル移動は補助平面の絵文字を分断しない。
- 案内: 設定に使い方・入力設定への導線・保存しない練習欄を追加。

### 実機で確認する項目

接続端末・エミュレータがないため、以下は未確認。

1. 「きょうはいいてんきです」を変換し、文節のタップ・前後移動・境界変更を繰り返す。意図しない確定や文字消失がないこと。
2. スペースの短いタップ・左右フリック・長押し・長押し後の往復・指を離す・途中キャンセルを区別できること。
3. Mozc／Karukan／zenzai、推論中の追加入力・回転・入力欄切替で古い結果が反映されないこと。
4. 定型文の複数行・再編集・削除・再起動後の復号・機密欄での非表示。
5. API 24/29/34/35/36 と片手・横画面で文節バーや定型文管理画面が操作できること。

rc.25-devはdebug署名のテスト用APK。操作感や実機での安定性を保証する記録ではない。

## rc.27-dev の文節カーソル同期

変換中の対象文節はハイライトと文節バーで示し、入力先のカーソルは未確定範囲の末尾に保つ。
書き換え直後の選択位置から範囲の末尾を推定しない。読みの途中編集でカーソルを戻す場合は、
書き換え前に取得した composing span の範囲と本文が前回の未確定文字に一致することを確認する。
範囲情報を返さない入力欄では推測した絶対位置に移動せず、末尾に保つ。

実機では、長文を変換し、文節の前後移動・縮小拡大を繰り返した後に入力・削除・確定を行う。
前後に確定済み文章がある場合や、入力先が遅れて選択通知を返す場合も、未確定範囲を壊さず
カーソルが範囲外へ移動しないことを確認する。接続端末がないため、この操作検証は未実施。
