# 変換候補UI（rc.29の試作）

## 操作

- 最初の「変換」で先頭候補を選択する。
- 変換中は6候補を番号付きのグリッドで表示する。通常幅では3列×2行、狭い幅では2列×3行とする。
- 「変換」の連打は表示中の6候補だけを巡回する。末尾の次は同じページの先頭へ戻る。
- 別ページへは左右の矢印（前／次）で進む。新しいページの先頭候補を選択する。
- 「一覧」でキーボードを隠し、取得した候補をスクロールして探す。「戻る」でキーボードへ戻る。
- 候補をタップすると確定する。全文のAI候補は一覧で「全文」と表示し、文節候補の巡回には混ぜない。
- 文節移動・境界の縮小／拡大は既存の文節操作バーで行う。編集中の文節は下線・背景で示し、入力欄のカーソルは変換範囲の末尾に置く。

## 実装上の制約

Mozcの `all_candidate_words` から最大120件を取得する。候補のフォーカスには候補IDを使い、Mozcの全体番号を表示ページ内の配列添字として扱わない。全候補が取得できなければ、その出力で取得できた候補のみを使う。全辞書候補を網羅する表示ではない。

通常入力中の予測候補は従来の1行／2行表示を維持する。6件表示は明示的な変換中に適用する。古い候補ビューから遅れて届いたタップは、現在の候補ID・本文と一致しなければ受け付けない。

## 検証

ページ外へ進まない巡回、端のページ、先頭候補の選択、Mozcの全体番号からのID解決を単体テストで確認する。実機での表示・操作検証は未実施である。特に大きな文字、片手・横画面・分割画面、一覧から復帰したときの高さ、複数文節の連続操作、AI変換との併用を確認する必要がある。
