# NFC による設定・学習の移行（実験的）

両端末でバックアップ画面から「NFC で設定・学習を移行」を開き、一方で送信、
もう一方で受信を選ぶ。NFC を有効にし、受信完了まで端末を近づけ続ける。
送信側には Android の HCE 対応が必要。32 MiB を超えるデータは送信しない。

移行には一時的な ECDH 鍵交換と AES-GCM で保護したパスフレーズを使い、
既存の暗号化バックアップを NFC 経由で送る。第三者のネットワークやクラウドは使わない。
鍵交換は相手の本人確認を行わないため、自分の端末同士で操作する。NFC の通信には時間がかかる。受信成功後、アプリを終了して起動し直すと設定と学習が反映され、
受信側の同じ項目は上書きされる。操作前に受信側のバックアップを取る。

現在の対象は設定、背景、Mozc の学習と辞書など。zenzai-plus のモデル・TTT 重みは対象外。
NFC のみでは巨大な TTT 重みの転送が長時間になり、既存バックアップのメモリ制限も超えるため、
別途ストリーミング可能な転送が必要。NFC 実機 2 台での検証は未実施。
