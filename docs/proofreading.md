# Qwen3 による端末内の文章校正

キーボード上部のツールメニューから「AI 文章校正」を開く。選択した文章、またはカーソル直前の最大600文字を対象に、端末内で校正する。モデルを一度ダウンロードした後は、校正時に文章をネットワークに送信しない。パスワード欄や学習禁止を要求する入力欄では無効。適用前に元の文章と校正結果の差分を表示し、入力欄が変わっていた場合は上書きしない。モデルは画面から削除できる。

候補は Apache-2.0 の Qwen3 0.6B / 1.7B を Unsloth が Q4_K_M に量子化したもの。固定リビジョン、サイズと SHA-256 は [候補情報](research/proofreading-models.json) を参照。モデルの選択肢に端末の空きメモリと空き容量からの推奨を表示する。空きメモリ 3500 MiB 以上、空き領域 1600 MiB 以上なら 1.7B、それ以外は 0.6B を推奨する。利用者はどちらも選べる。推奨は概算で動作保証ではない。

実行部は TTT を使う zenzai とは独立した llama.cpp による arm64 専用ライブラリ。ソースは `native/proofread`、ビルドは `scripts/build_proofread.sh`。llama.cpp は `https://github.com/azooKey/llama.cpp` から取得し、参照リビジョンは `66afb885a8ddcc0511798aec9fb5a01017941018`、ライセンスは MIT。推論は中断・300秒の制限があり、全文生成されなかった出力は表示しない。
