# 端末内のAI文章校正（Qwen3.5 / Qwen3）

キーボード上部のツールメニューから「AI 文章校正」を開く。選択した文章、またはカーソル直前の最大600文字を対象に、端末内で校正する。画面はキーボードの代わりに画面下部の小窓として開き、背後の入力欄を見ながら操作できる。文章を取得できなかった場合でも空欄から手入力して校正できる。パスワード欄や学習禁止を要求する入力欄では無効。校正用の入力欄は個人学習を抑制する（`IME_FLAG_NO_PERSONALIZED_LEARNING`）。

## 校正画面でできること

- 取得した文章を校正前に編集・追記する。
- 書き換えの種類を選ぶ。誤字・文法を直す / 丁寧にする / 簡潔にする / 自然な文章にする / 自由に指示する。
- 自由指示では、書き換え方を自由に入力する（200文字以内）。
- 生成結果を、元の文章との差分（色付きが変更箇所）で確認する。
- 結果を見てから「適用」「適用しない」「コピー」を選ぶ。
- 生成後に元の文章や指示を変えると、その結果は古いものとして扱い、適用できない。誤って古い結果で上書きしない。
- 「モデルをダウンロード／モデルを管理」から専用の「AI 文章校正モデル」画面を開き、モデルの取得・削除・選択ができる。同じ画面へ設定からも入れる。

モデルを一度ダウンロードした後は、校正時に文章をネットワークに送信しない。モデルは専用画面から削除できる。Qwen3.5 / Qwen3 の校正用モデルと、変換に使う zenzai-plus のモデルは別物である。

## 適用（反映）

結果を適用するときは、戻った先の入力欄と校正対象が同じか（パッケージ・フィールド・入力種別）、元の文章が変化していないかを確認してから置換する。確認には `getSelectedText()`、`getTextBeforeCursor()`、`getExtractedText()`、対応端末では `getSurroundingText()`（Android 12 以降）を使う。安全に確認できないときは別の文字を消したり上書きしたりせず、コピーを案内する。`InputConnection` が例外を返しても IME は落ちない。戻った直後に `InputConnection` がまだ使えない場合は、少し待ってから再試行する。

## モデル候補

候補は Apache-2.0 の Qwen3.5 0.8B / Qwen3 1.7B（Qwen）と Gemma 4 E2B（Google DeepMind）を Unsloth が Q4_K_M に量子化したもの。固定リビジョン、サイズと SHA-256 は [候補情報](research/proofreading-models.json) を参照。モデルの選択肢に端末の空きメモリと空き容量からの推奨を表示する。空きメモリ 3500 MiB 以上、空き領域 1600 MiB 以上なら Qwen3 1.7B、それ以外は Qwen3.5 0.8B を推奨する。利用者はどれでも選べる（Gemma 4 E2B は約3.11 GB と大きい）。推奨は概算で動作保証ではない。品質は保証せず、差分を見てから適用する前提とする（小さいモデルは指示を守らない・意味を変える場合がある）。

## プロンプト

プロンプトの組み立ては `ProofreadPrompt.kt` に分離している。種類ごとの指示文、自由指示、文章と指示の長さ制限（文章600文字・指示200文字）、利用者テキストからの制御トークン（`<|...|>`）の除去、出力からの思考ブロックの除去を行う。ネイティブ実行部はチャットテンプレートを適用しないため、family ごとの書式（Qwen は ChatML、Gemma は `<start_of_turn>`）をここで組み立てる。Qwen 系は assistant ターンに空の thinking ブロックを前置して思考出力を抑制する。校正対象の本文に `/no_think` を付加しない（本文としてコピーされる不具合を rc.28 で修正）。元の本文にない `/no_think` や `/think` が結果に混入した場合は結果を破棄し、適用・コピーに渡さない。元の本文自体にある同文字列は勝手に削除しない。Gemma 系は `<|think|>` を入れない。system の指示は、小さなモデルでも扱いやすくし `n_ctx=2048` の prefill を圧迫しないよう、要点（本文だけを出力／説明・マークダウン禁止／意味・数値・改行を変えない・翻訳しない／不要箇所はそのまま）に絞って短く保つ。必要なら thinking 終了マーカー（Qwen の `</think>`、Gemma の `<channel|>`）以降だけを取り出す。

## 実行部

実行部は TTT を使う zenzai とは独立した llama.cpp による arm64 専用ライブラリ。ソースは `native/proofread`、ビルドは `scripts/build_proofread.sh`。llama.cpp は `https://github.com/azooKey/llama.cpp` から取得し、参照リビジョンは `66afb885a8ddcc0511798aec9fb5a01017941018`、ライセンスは MIT。推論は中断・300秒の制限があり、全文生成されなかった出力は表示しない。
