まず、共通のところ

プライバシーは、ほぼ互角です。

どちらも入力・学習・辞書を端末内で扱い、Keystore で暗号化し、クラウドバックアップを無効にしています。Zinna は権限ゼロ、Komorebi は任意取得のための INTERNET だけ。この点は Zinna が上です。

ここは、差がつきません

  • 入力・変換・学習を端末内で処理
  • 入力内容を外部へ送信しない
  • 広告SDK・解析SDKなし
  • 学習履歴と辞書を Android Keystore の鍵で暗号化
  • allowBackup=false（クラウドバックアップ無効）
  • ソースコード公開（Apache-2.0）

違い

土台は同じ。上に載せたものが違う。

01

AI を、端末内で使える

Karukan の変換、Qwen / Gemma の文章校正、zenzai-plus の学習。どれも端末内で動きます。Zinna の zenzai は実験的な位置づけで、校正と Karukan は載っていません。

02

辞書を、選んで足せる

NEologd と SKK の6データセットを取得して切り替えられます。複数選ぶと統合データセットで同時に使えます。意味辞書と ★ の優先指定も追加。Zinna は同梱辞書とユーザー辞書までです。

03

機種変更が、NFC で終わる

暗号化バックアップと復元、NFC による設定・学習の移行、NFC でテキストを送る Meets Beam。移行まわりは Komorebi で足した部分です。

04

毎日の操作を、減らす

片手モード、絵文字パレット、定型文、キーボード高さの調整、アプリ別プロファイル、パフォーマンス診断。入力の回数ではなく、入力の手間を減らす機能です。

FAQ

よくある質問。

Zinna-IME より安全ですか？

プライバシーはほぼ互角です。Zinna は権限がゼロで、Komorebi は任意取得のための INTERNET だけ。入力・学習・辞書を端末内で扱い、暗号化する点は同じです。機能を取るか、権限ゼロを取るか、という違いです。

元に戻せますか？

戻せます。どちらも別アプリとして共存するので、Android の設定でキーボードを切り替えるだけです。ユーザー辞書は TSV で書き出して移せます。

Zinna-IME から設定を移せますか？

ユーザー辞書は Mozc / Google 日本語入力互換の TSV で取り込めます。ただし application ID が違うため、学習履歴や設定の自動移行はありません。

Zinna-IME はこれからも残りますか？

はい。Komorebi はフォークで、上流の更新を取り込んでいます。Zinna 側の開発を妨げるものではありません。どちらも Apache-2.0 です。

どちらを選べばいいですか？

権限ゼロと最小構成を重視するなら Zinna。AI・追加辞書・移行・便利機能まで使うなら Komorebi。プライバシーの芯は同じなので、欲しい機能で選んでください。

同じ芯で、できることが多いほうへ。
