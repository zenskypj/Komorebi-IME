変換を1回押した直後から、確定キーで選択中の文節までを確定し、次の文節の候補を表示します。左右キーで区切りを調整できます。全文候補を自分で選んだ場合は全文を確定します。

内蔵固有名詞辞書とユーザー辞書では、フルネームを残したまま、読みの境界を確認できた姓・名も個別に変換できます。内蔵辞書に1,723件の姓・名候補を追加しました。「かりんさん」と入力したときに「夏鈴さん」のような敬称付きの候補も出ます。

入力中に文章の区切りを別セッションで解析して候補へ追加し、フリックの近い操作を補正に反映します。Android 13 以降のシステムスタイラス入力、写真の位置に合わせたキー文字色、キー画像を含む配列・テーマの共有に対応しました。

変換エンジンの候補・遅延を同じ評価例で比較するスクリプトを追加しました。実機での精度や速度はまだ測っていません。

実際の端末でのスタイラス、編集先への反映、候補順位、音声、画像表示、バックアップ復元は未確認です。配布する本体と音声モジュールは debug 署名のテスト APK（`me.zssu.ime.debug`、`me.zssu.ime.voice.debug`）です。
