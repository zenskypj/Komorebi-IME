`0.3.0-rc.44-dev` のユニバーサルdebug署名APK予定版です（`me.zssu.ime.debug`、versionCode 68）。

## 変更

- Meets Beam の大容量データ転送対応：NFC での高速認証・接続情報（OOB）交換後、端末間 Wi-Fi Direct（P2P）へ自動ハンドオフして高速ストリーミング転送する基盤 `BeamHandover` を実装。
- 画像・動画・音楽・ドキュメントなどの各種ファイル共有に対応。Android 共有メニュー（`*/*`）の「Meets Beam で送る」から直接送信可能。
- ユーザー辞書・辞書パック（.kdict / TSV）のワンタップ直接ビーム共有を追加。ユーザー辞書画面に「Beam」ボタンを新設し、受信側はワンタップで自身のユーザー辞書へ安全に取り込み可能。
- 完全ローカル・ゼロクラウド通信：外部サーバーやクラウドを一切介さず、端末間 P2P 暗号化（AES-GCM）通信のみで完結。

## 検証

- `BeamHandoverTest` 単体テスト追加（ペイロードの JSON 相互変換、AES-GCM ループバック暗号化ストリーミング送受信、不正トークン拒絶検証）。
