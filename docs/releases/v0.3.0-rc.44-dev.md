`0.3.0-rc.44-dev` のユニバーサルdebug署名APKです（`me.zssu.ime.debug`、versionCode 68）。正式署名版ではありません。

## 変更

- Meets Beam の大容量転送に Wi-Fi Direct（P2P）を追加。NFC でグループオーナーの端末アドレス・IP・一時トークンを交換し、Wi-Fi Direct のグループへ接続してストリーミング転送する。
- 画像・動画・音楽・ドキュメントの共有に対応。転送は AES-GCM で暗号化し、宣言サイズと SHA-256 を照合する。受信ファイル名はアプリ内でサニタイズし、アプリ専用領域へ保存する。
- ユーザー辞書・TSV 辞書の共有を追加。ユーザー辞書画面の「Beam」から送信し、受信側は内容を確認して「置き換える」を選んだときだけ取り込む。従来の NFC で送れる小型辞書も同じ確認を通す。
- 権限を追加: `ACCESS_WIFI_STATE` / `CHANGE_WIFI_STATE` / `NEARBY_WIFI_DEVICES`、Android 12 以下に限り `ACCESS_FINE_LOCATION` / `ACCESS_COARSE_LOCATION`。位置情報は Wi-Fi Direct の端末検出だけに使い、位置の記録・送信はしない。`INTERNET` は従来どおり任意のモデル・辞書取得だけ、`NFC` は Meets Beam と NFC 移行だけに使う。
- クラウドや外部サーバーは経由しない。受信したファイルは「ファイルを開く／共有」から開く。
