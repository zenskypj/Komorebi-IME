背景とキーを、それぞれ好きな見た目に変えられるようにしました。背景プリセットは13種、新しい完成テーマは9種です。

- **キーの枠**：個別枠、仕切り線、枠なし、塗りつぶし、破線、グラデーション。線幅・角丸・濃さも調整できます。
- **キーごとの外観**：枠・色・文字・画像を個別に指定できます。変換キーだけ猫の絵にしても、変換キーとして動きます。
- **背景**：写真1〜4枚のスライドショーと無音の背景動画に対応。動画の再生範囲、背景の位置・明るさ・ぼかしなどを調整できます。
- **文字と演出**：書体、フリックガイド、候補・ツールバーの配色、キー音、タップ演出、特定の語を確定したときに表示する画像を設定できます。
