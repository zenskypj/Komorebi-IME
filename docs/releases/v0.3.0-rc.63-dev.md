きせかえで写真・動画・背景プリセットを選ぶと、画像の代表色を使って文字、キー、候補、ツールバーなどの配色をまとめて調整します。「配色」から画像に合わせ直したり、文字とアイコンの色を一括変更したり、各部分を手動で調整したりできます。「完了」でテーマとして適用します。

直近の自分の画像・動画を背景一覧に表示し、選択中の印を付けます。プリセットへ切り替えた後も選び直せます。不要になったコピーは一覧から削除できます。元の写真や動画は削除しません。複数写真は最初の写真、動画は先頭フレームから配色を作ります。画像によっては手動調整が必要です。
