# Komorebi IME 0.3.0-rc.2

上流 Zinna-IME `81e04e6` の更新を選択的に統合したテスト用 Release Candidate です。
正式版ではありません。versionCode は 26 です。

## 変更内容

- 学習履歴・ユーザー辞書・設定・配列・テーマなどのパスフレーズ付きバックアップと復元。
- 日本語の左文脈を使う助詞の順位改善。
- カタカナ英語辞書20,953件をMozcシステム辞書へ統合。
- 数字面の半角スペース、クリップボード変更検出、Mozc生成元の固定。
- 任意モデル同梱ビルド向けzenzai-plusの推論・TTT・辞書学習・暗号化保存処理。
- 上流のUnlicense OR MIT-0原文と表示を追加。既存のApache 2.0・第三者表示は維持。

KarukanとKomorebi独自の入力・候補・外観機能は維持しています。
jawikiとF-Droid向け設定は今回の対象外です。出典条件が明確でないスクレイピング由来辞書も
従来の配布方針どおり同梱していません。

## 添付APKについて

添付はすべて **debug署名のテスト用APK** です。application ID は `me.zssu.ime.debug` で、
正式版の `me.zssu.ime` とは別アプリとして扱われます。署名鍵が異なる既存のdebug版からは
そのまま更新できない場合があります。削除・再インストールするとアプリ内データが消えるため、
事前に利用できるバックアップ手段で保全してください。

通常は `universal` を選択してください。CPUが分かる場合は対応するABI別APKを選択できます。
`SHA256SUMS.txt` には添付APKのSHA-256を記載しています。
正式署名のないrelease APK/AABは利用者向けの添付には含めません。

## 検証と制限

- JVMテスト: app 136件、mozc 5件、karukan 2件。失敗・エラー・スキップなし。
- Mozcネイティブ回帰テスト: 3ケース成功。
- リリース前のclean・Lint・debug/release APK・AABとABI分割ビルドを実行して成果物を確認。
- APKのID・バージョン・16KB ZIP整列、必須ライブラリとライセンス収録を確認。

zenzai-plusの互換ランタイムと指定モデルは未入手で、**このAPKにはzenzaiモデルもランタイムも
同梱していません**。通常ビルドの設定では有効化できません。実モデルでの推論・TTTは未検証です。
Karukanの任意モデル取得と変換機能は引き続き利用できます。

API 24 / 29 / 34 / 35 / 36の実機・エミュレータでの操作マトリクス、端末間のバックアップ復元、
実機でのエンジン切り替えは今回未確認です。zenzaiのモデル・TTT状態はバックアップ対象外です。
詳しい取り込み・検証記録は `docs/upstream-sync.md` を参照してください。
