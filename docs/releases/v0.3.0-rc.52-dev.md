設定に **「きせかえ」** を独立して追加しました。スクロールしてもキーボードのプレビューが残り、フリックとQWERTYを切り替えて試し打ちできます。

- 完成テーマと配列プリセットを専用画面に集約しました。適用する前に、サムネイルや配列名を選んで試せます。
- 「キー」で個別枠、仕切り線、枠なし、破線などを切り替え、四角・角丸・大きな丸み、間隔、画像を調整できます。キーを一つずつ編集する画面にも進めます。
- 背景、配色、文字、キー音、演出を同じ画面に集めました。テーマの調整は「保存して適用」で別テーマとして保存でき、写真・動画の選択は背景に即時反映します。
- 配列やテーマのJSON入出力は、それぞれの「詳細」にまとめました。高さや片手モードは「表示とサイズ」で調整できます。
