カスタム写真・動画を選んだとき、自動配色で画像の上に色が強く乗っていた問題を改善しました。キー面は8%の濃さ、上段のツールバーと通常の候補欄は透明にし、フリックガイドと展開したツール一覧には背景を残します。新しく読み込む写真・動画の背景の濃さは100%から始まり、後から手動で調整できます。付属の背景プリセットの自動配色は従来どおりです。

左右の矢印キーを上・下にフリックすると、入力欄の前後の行にカーソルを移動します。未確定文字がある場合は先に確定します。入力先アプリへ上下キーを送り、拒否された場合は改行区切りで移動します。カスタム配列で既に上下方向に操作があるキーは、その割り当てを維持します。

以前に保存したテーマは、画像を選び直すか「きせかえ」→「配色」→「背景画像に色を合わせる」→「完了」で新しい配色を適用できます。画像や文字色によっては見づらい箇所が残るため、手動で調整してください。
