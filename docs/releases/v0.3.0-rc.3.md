# Komorebi IME 0.3.0-rc.3

操作記号のアイコン化を含むテスト用 Release Candidate です。正式版ではありません。
versionCode は 27 です。

## 主な変更

- Backspace、Enter、カーソル移動、Undo、Shift、スペースの操作表示をアイコンに統一。
- Shift の通常・一回・固定を異なるアイコンで表示。
- 候補の最優先、お気に入り、配列・テーマ編集画面の選択表示にもアイコンを使用。
- 文字として入力する記号やカスタムラベルは保持。
- Apache 2.0 に基づく Material アイコンの帰属表示を更新。

0.3.0-rc.2 に含まれたバックアップ、辞書統合、文脈を使った変換改善も含みます。
前の環境で未コミットだった zenz-v3.2 のダウンロード・変換対応は、この版には含まれていません。
zenzai-plus のモデル・専用ランタイムも未同梱です。

## 添付 APK

添付は **debug 署名のテスト用 APK** で、アプリ ID は `me.zssu.ime.debug` です。
正式版の `me.zssu.ime` とは別アプリです。既存の debug 版と署名鍵が異なる場合は上書き
インストールできません。アプリを削除するとデータも消えるため、削除前に保全してください。
通常は universal APK を、CPU が分かる場合は対応する ABI 別 APK を選んでください。
`SHA256SUMS.txt` に各 APK の SHA-256 を記載しています。
正式署名のない release APK/AAB は添付しません。

## 制約

API 24 / 29 / 34 / 35 / 36 の実機・エミュレータでの操作、端末間バックアップ復元、
エンジン切り替え、および zenzai-plus の実モデルによる推論・学習は今回未確認です。

- 単体テスト 145 件（app 138 件、Mozc 5 件、Karukan 2 件）、debug／release Lint が成功。
- debug／release APK、release AAB、および CPU 別 APK のビルドが成功。
- 添付する debug APK の署名、16 KB 配置、Mozc データとライセンス文書の同梱を確認。
