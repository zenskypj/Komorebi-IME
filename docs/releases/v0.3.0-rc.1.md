# Komorebi IME 0.3.0-rc.1

正式版に向けた最初のRelease Candidateです。入力内容とAI文体補正は端末内で処理されます。

## 主な改善

- Enterを確定・送信/検索・通常改行・物理キーへ正しく振り分け、入力欄が宣言した操作を
  拒否した場合だけ安全に次の方式へフォールバックするようにしました。
- Android 7–14でナビゲーション余白を二重加算せず、Android 15–16で実際に重なるOS操作
  領域だけを避けるようInsets処理を刷新しました。背景や濃さの変更直後も位置を維持します。
- Karukanの明示変換をMozcとのハイブリッド順位付けにし、両エンジンの一致、ユーザー優先、
  文脈候補を統合しました。推論中の追加入力・キャンセル時の古い候補確定も防止します。
- AI文体補正の表現辞書と節解析を拡張し、引用、URL、メール、インラインコード、コード
  ブロックは保護して周囲だけを補正するようにしました。
- 低RAM端末のKarukanスレッド数を抑え、画面非表示時にモデルを解放し、終了処理で
  メインスレッドを待たせないよう軽量化しました。
- Android 12以降のクラウドバックアップと端末間転送にも、辞書・変換学習・設定を含む
  全アプリデータの除外を明示しました。
- Android 14の非線形フォント拡大、Android 16 / API 36.1向けビルド、16 KBページ配置、
  R8後のJNI名保持、OSSライセンスとプライバシー表示を検証しました。

## 検証

- 125ユニットテスト: 125成功 / 失敗0
- Debug / Release lint: エラー0
- Debug APK、縮小済みRelease APK、Release AAB、5種類のABI別APKをビルド
- 全Release APKを `zipalign -c -P 16 -v 4` で検証
- APK内のMozc/Karukanネイティブ、`mozc.data`、プライバシー文書、OSSライセンスを確認

## APKについて

今回添付するAPKはRC評価用のdebug署名ビルドで、application IDは
`me.zssu.ime.debug`です。既存の正式署名版と並行して導入できます。通常は
`app-universal-debug.apk`を選び、容量を抑えたい場合だけ端末CPUに合うABI版を選んでください。

正式版用の署名鍵はリポジトリ外で管理しているため、未署名Release APK/AABは添付しません。
公開前の人手確認項目は[正式版リリース受け入れ基準](../release-readiness.md)を参照してください。
