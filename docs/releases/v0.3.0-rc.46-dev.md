`0.3.0-rc.46-dev` のユニバーサルdebug署名APKです（`me.zssu.ime.debug`、versionCode 70）。正式署名版ではありません。

## 変更

rc.45で「Wi-Fi Direct の端末アドレスを取得できません」と表示される端末への対応です。

- 送信側は、Wi-Fi Directの端末アドレス（MAC）が取得できなくても処理を止めなくなりました。端末名（`WifiP2pDevice.deviceName`）をNFCの接続情報へ載せ、受信サーバーとNFC送信をそのまま進めます。
- 受信側は、検出したピアを次の順で照合します。
  1. NFCで受け取った端末アドレスと一致するピア
  2. 端末名が一致するピア
  3. 検出したピアが1台だけならそのピア
- NFCの接続情報は`ownerAddress`を空にできるようにし、端末名だけでも受け渡せるようにしました。接続時のAES-GCMトークン認証は従来どおりなので、別の端末へ接続してしまっても転送データは復号できません。
- 相手を特定できない場合は「Wi-Fi Direct の相手を特定できません。端末名を確認して再試行してください」と表示します。複数のWi-Fi Direct端末が近くにある場合は、端末名の一致が必要です。
