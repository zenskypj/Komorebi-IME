## 変更

- かな読みからの通常の英語候補は、完全一致しても漢字・カタカナ・ひらがな候補より後ろに表示。内蔵・ダウンロード辞書とも対象。
- 予測・変換一覧で同じ規則を適用。辞書の完全一致優先によって英語が再び先頭へ戻る経路も修正。
- 英語候補は削除せず、Native ID・各群の相対順を維持。★最優先指定、個人登録と確認できたライブ候補、固有名詞の入力途中の予測、英字直接入力、AI自体の通常優先を維持。
- APIに辞書別の出典がないため、かな読みと英字のみの表記から判別（全角英字も対象）。混在表記・辞書コストの全面調整は対象外。
- 関連docs・FAQを更新。
