## 変更

Wi-Fi Directの接続方式を、送信側が`createGroup`でグループオーナーを固定する方式から、**標準のグループ交渉**へ変更しました。

- 送信側は`createGroup`をやめ、Wi-Fi Directの検出だけを開始します。
- 受信側はNFCで受け取った端末名／アドレスをもとに相手を検出し、`connect`します。グループオーナーはAndroidのフレームワークが自動決定します。
- **どちらの端末がグループオーナーになっても動く対称構成**にしました。
  - GO側: 受信サーバーを開いて待ち受ける
  - クライアント側: GOのIPへ接続する
  - 送信側がGOならGOが送信、受信側がGOならGOが受信する
- ポートは49152〜49161の共通範囲を使い、GOが空いているポートをバインド、クライアントが同じ範囲を探索します。
- 4つの経路（サーバー送信・サーバー受信・クライアント送信・クライアント受信）を実装し、ループバックテストで送受信を確認しました。
- NFCの接続情報は一時トークンと端末名が中心です。端末アドレスが取得できない端末でも送信側は停止しません。
- 接続待ちのタイムアウトを180秒へ延長しました。
