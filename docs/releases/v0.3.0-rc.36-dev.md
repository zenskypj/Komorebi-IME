`0.3.0-rc.36-dev` のテスト用 APK です。**ユニバーサル debug 署名版**（`me.zssu.ime.debug`、versionCode 60）で、正式署名版ではありません。実機での操作確認は未実施です。

## rc.35-dev からの変更

- 追加システム辞書の**切り替えを高速化**しました。
  - 切り替え前の不要なコンバータ再読み込み（`RELOAD_AND_WAIT`）を削除。新しいモジュールでコンバータは作り直されるため不要でした。
  - 適用待ちのポーリングを **300回 × 100ms（最大30秒）** から、**40ms 開始・最大250ms の指数バックオフ（総額12秒）** へ。各回でセッションを作り直していた処理を大幅に減らしました。
  - データセットの **SHA-256 検証をプロセス内でキャッシュ**し、切り替えのたびに 80MB 級を再ハッシュしないようにしました。
- ユーザーマニュアルと**ドキュメントサイト**（GitHub Pages）を公開しました。はじめての設定から詳細仕様まで、全37リリースのタイムライン、ほかのIMEとの比較、フォーク元 Zinna-IME との比較を掲載しています。
- サイトのモバイル表示を修正しました（ヘッダーの折返し、サイドバーのスクロール、比較表をスマートフォンではカード表示に）。
