## 添付 APK

添付は **debug 署名のテスト用 APK** で、アプリ ID は `me.zssu.ime.debug` です。
正式版の `me.zssu.ime` とは別アプリです。既存の debug 版と署名鍵が異なる場合は
上書きインストールできません。アプリを削除するとデータも消えるため、削除前に保全してください。
通常は universal APK を、CPU が分かる場合は対応する ABI 別 APK を選んでください。
`SHA256SUMS.txt` は各 APK の SHA-256 です。正式署名のない release APK/AAB は配布しません。
