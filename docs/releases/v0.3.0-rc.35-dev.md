## rc.34-dev からの変更

- 追加システム辞書を複数同時に有効化できるようにしました。「変換エンジン・辞書」で辞書を複数選ぶと、選択したすべてを含む統合データセット（NEologd統合 / SKK統合 / 全部入り）が使われます。単体辞書は従来どおり選択できます。
- 統合データセットを固定ソースから実生成しました。
  - `neologd`（NEologd 統合 / 2データセット）: 保存 78.4 MiB・取得 47.6 MiB
  - `skk`（SKK 統合 / 4データセット）: 25.9 MiB・17.3 MiB
  - `all`（全部入り / 6データセット）: 85.6 MiB・51.9 MiB
- 統合のため、生成側の value-trie id 上限を 22bit→24bit へ緩和するパッチを当てています。crammed 形式の上位6bitが全て1になる id は、トークン先頭バイトが終端フラグ `0xff` と衝突するため、その場合は3バイト形式を使用します。出力形式は変えないため、アプリ同梱の libmozc は無改修で読み出せます（互換指紋も不変）。
