## 変更

- 変換キーを1回押して候補が開いた直後の確定を、選択中の文節ではなく文全体の確定に変更。長い文を一度で確定できる。
- 変換キーをもう一度押す、文節を移動・タップする、候補を選ぶ、候補一覧を開く、入力を編集する、のいずれかを行った後は、従来どおり選択中の文節までを確定して次の文節へ進む。
- 変換開始時に文節が1つしかない場合は従来と同じ結果になる。判定は `WholeSentenceConfirm` に分離した。
