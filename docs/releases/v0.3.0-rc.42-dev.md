`0.3.0-rc.42-dev` のユニバーサルdebug署名APKです（`me.zssu.ime.debug`、versionCode 66）。正式署名版ではありません。

## 変更

- Mozcの初期化・変換・文節操作・確定・入力設定の反映を専用の直列ワーカーへ移し、待っている間にUIを描画可能に。入力欄とViewの操作はUI側へ戻す試験的な非同期実装。
- 同じ入力先の文字・削除・変換・確定を受付順に処理。配列・機密欄／補正／トグル設定もキー受付時の内容を保持。入力先切り替え・終了・外部消去時には古い未処理イベントと結果を破棄し、新しい入力先へ適用しない。

- QWERTY・Godan・単純な数値パッドで不要なフリック連打用Mozcコマンドを削減。フリックの連打・濁点処理は維持し、捨てる中間候補の組み立てだけ省略。
- Native候補と補助候補の二重描画、補助候補がないときの二重順位付けを削減。AI結果到着時の更新は維持。
- 2行候補とツールバーの表示部品を再利用。同じ文字・★アイコン・背景の不要な再設定を削減。
- Android 12以降の送信後チェックでは小さな周辺テキストを先に取得。未対応の入力先・旧APIは短い抽出テキスト要求へフォールバック。送信済み文字が再出現する対策は維持。
- 候補行数・固有名詞先読み・★優先を維持。キー文字を間引かない。関連マニュアル・仕様・FAQを更新。

## 高速化の見込み（未実測）

**全体の入力速度が何%向上するかは、まだ算定できません。** 以下はrc.41とのコード上の比較による処理回数の削減率で、端末で測った速度向上率ではありません。

| 対象 | 削減の見込み・根拠 | 条件 |
| --- | --- | --- |
| 通常のQWERTY・Godan・単純な数値パッドのキー送信 | **Mozcへのコマンド呼び出しを50%削減**（停止＋キー送信の2回→キー送信1回） | トグルOFF、初期化・設定変更を除く通常入力 |
| 日本語の即時候補表示 | **候補欄の更新回数を50%削減**（Native表示＋補助候補表示の2回→統合表示1回） | ライブ候補の対象となる入力。後着のAI結果による更新は別 |
| 2行候補・ツールバーのビュー再生成 | **再生成を100%削減できる区間あり**（毎回の作り直し→既存ビューの再利用） | 枠数・表示形式・ツール設定が変わらない連続更新。初回表示・パネル切り替え等を除く |
| UIスレッドでのMozc入力処理の同期完了待ち | 専用ワーカーへ移動し、**この待ちによる直接のUI占有を設計上100%除去** | JNIの実行時間自体が100%短縮する意味ではない。UI更新・入力先への問い合わせ・キュー待ちは残る |

**条件付きの時間試算：** 削減対象が従来の処理時間の40%を占め、その部分の所要時間も半減する場合、全体の処理時間は**20%短縮**し、同じ時間内の処理量は**約25%増加**する計算です。ただし「40%を占める」「所要時間も半減する」は未確認の仮定であり、rc.42全体の予測値・実測値ではありません。

呼び出し回数と所要時間は比例するとは限りません。非同期化だけではMozc本体の計算は速くならず、スレッド間受け渡しの負担も増えるため、文字反映までの時間が短縮しない場合もあります。本版でまず狙うのは、変換待ちでキー表示やフリックガイドが止まることを減らすことです。

長押しの自動リピート（削除・カーソル移動など）は、待機／実行中を合わせて1イベントまでに抑えます。指を離すと未実行分を取り消し、最初の通常押下は保持し、自動反復は既に受け付けて実行中の1回だけ完了します。Native処理が遅いときに削除や移動が大量に溜まって後から続くことを防ぎます。通常の物理打鍵や指の移動量に対応する操作は間引きません。
