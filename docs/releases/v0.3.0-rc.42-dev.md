`0.3.0-rc.42-dev` のユニバーサルdebug署名APKです（`me.zssu.ime.debug`、versionCode 66）。正式署名版ではありません。

## 変更

- Mozcの初期化・変換・文節操作・確定・入力設定の反映を専用の直列ワーカーへ移し、待っている間にUIを描画可能に。入力欄とViewの操作はUI側へ戻す試験的な非同期実装。
- 同じ入力先の文字・削除・変換・確定を受付順に処理。配列・機密欄／補正／トグル設定もキー受付時の内容を保持。入力先切り替え・終了・外部消去時には古い未処理イベントと結果を破棄し、新しい入力先へ適用しない。

- QWERTY・Godan・単純な数値パッドで不要なフリック連打用Mozcコマンドを削減。フリックの連打・濁点処理は維持し、捨てる中間候補の組み立てだけ省略。
- Native候補と補助候補の二重描画、補助候補がないときの二重順位付けを削減。AI結果到着時の更新は維持。
- 2行候補とツールバーの表示部品を再利用。同じ文字・★アイコン・背景の不要な再設定を削減。
- Android 12以降の送信後チェックでは小さな周辺テキストを先に取得。未対応の入力先・旧APIは短い抽出テキスト要求へフォールバック。送信済み文字が再出現する対策は維持。
- 候補行数・固有名詞先読み・★優先を維持。キー文字を間引かない。関連マニュアル・仕様・FAQを更新。

長押しの自動リピート（削除・カーソル移動など）は、待機／実行中を合わせて1イベントまでに抑えます。指を離すと未実行分を取り消し、最初の通常押下は保持し、自動反復は既に受け付けて実行中の1回だけ完了します。Native処理が遅いときに削除や移動が大量に溜まって後から続くことを防ぎます。通常の物理打鍵や指の移動量に対応する操作は間引きません。
