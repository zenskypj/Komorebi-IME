`0.3.0-rc.38-dev` のユニバーサルdebug署名APKです（`me.zssu.ime.debug`、versionCode 62）。正式署名版ではありません。

## 変更

- 利用者提供JSONLの4,468件を、既存の同梱固有名詞辞書へ合併。追加取得するネット辞書にはしていません。
- 既存側の重複15行・追加分との重複106語を整理し、合計4,879語（純増4,362語）に。人名・地名・組織を区別。
- 原本JSONL・既存原本・統合スクリプト・統計をリポジトリに保存。元のcostは原本に保持しますが、既存のTSV取り込みでは語ごとのコストに適用できません。
- 従来の「有名固有名詞」スイッチで使用。無効設定はアプリ更新後も尊重し、個人辞書・学習履歴は維持。
- rc.37の補正・最優先・送信後の状態破棄と、rc.36までの更新を維持。

## 作成条件

前の指定を継続し、追加の単体テスト・lint・実機確認は省略。データを精製し、低負荷設定（並列1・Gradleヒープ2GiB・CPU認識2・常駐なし）でdebug APKを作成します。
nativeや大規模なネット辞書パックの再生成はしていません。実機での候補順位・文章変換は未確認です。
