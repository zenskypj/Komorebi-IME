## 変更

rc.44でWi-Fi Directが動作しないという報告を受け、接続経路を修正しました。

- Wi-Fi Directの`discoverPeers` / `requestPeers`は、Android 13以降でも**端末の位置情報モードがオン**でないと動作しません。送受信前に全Androidで確認し、オフなら理由を表示するようにしました。アプリが位置情報を取得・送信するわけではありません。
- 送信側はNFC送信前にWi-Fi Directグループを作成し、**受信サーバーを先にバインド**してから、実際の空きポートをNFCの接続情報へ載せる方式に変更しました。固定ポート49152の競合と、P2Pインターフェース確立前のバインド失敗を避けます。
- グループオーナーの端末アドレスは、ローカルP2P情報 → `requestDeviceInfo` → グループ情報の順で取得し、`02:00:00:00:00:00`などのプレースホルダーMACを拒否します。取得できない場合は最大5秒再試行します。
- グループオーナーIPが未確定の場合は`p2p`インターフェースのIPv4を走査し、送信サーバーのバインドを最大30秒リトライします。
- 受信側は`connect`の再試行、`NetworkInfo.isConnected`の確認、接続タイムアウトの90秒への延長、接続成立後のグループオーナーIP取得のフォールバックを追加しました。
- 共有元がサイズを返さない場合は`AssetFileDescriptor.length`で補完します。取得できない場合は従来どおり理由を表示します。
- 各段階（グループ作成、サーバー待機、NFC送信、探索、接続、受信）を画面の状態表示へ出し、どこで止まったか分かるようにしました。
