`0.3.0-rc.29-dev` は変換候補UIの変更とAI文章校正の結果保護を試すテスト版です。ユニバーサル debug 署名 APK（`me.zssu.ime.debug`、versionCode 53）で、正式署名版ではありません。

## rc.28-dev からの変更

- 変換中の候補を6件の番号付きグリッドへ変更。「変換」は表示ページ内だけを巡回し、別ページへは左右矢印、まとめて探すときは「一覧」を使用します。最初の変換は先頭候補を選びます。
- Mozcの全体候補番号とページ内番号を混同していたフォーカス解決を修正。文節候補は最大120件を取得し、全文AI候補は一覧から選べます。
- 古い候補ビューからのタップを拒否し、変換エンジンが状態を返さない場合に空白を混入させないようにしました。
- 「誤字・文法を直す」の結果を差分から組み立て、空白・改行・全半角だけの変更、検出できたURL・メール・コード・数値（符号含む）・名前の仮名読みを崩す変更を抑止します。独立した誤字・助詞・重複の訂正は残します。
- 校正結果が原文と同じ場合は、その旨を表示します。誤りがないとは判定しません。
- 小型モデルを維持し、0.8BのQ4/Q6/Q8と1.7BのQ4を同一条件で比較。今回の21例では量子化を弱める効果を確認できず、Q4を継続します。Gemmaへの自動切り替えや追加モデルの自動取得は行いません。

## 検証と制約

アプリ205件・Karukan 2件の単体テスト、debug/release lint、APK/AAB・ABI別ビルド、APK内容・16 KB配置・JNI名保持を確認しています。

実機およびエミュレータでの表示・操作、各Android世代の入力互換性、端末上でのモデル推論・速度・メモリは未確認です。変換UIは試作段階として、片手・横画面・大きな文字・一覧復帰・文節操作を実機で確認する必要があります。

校正比較はPC上の合成文21例であり、一般的な精度の保証ではありません。0.8B・1.7Bとも文中の誤変換の見逃しや誤訂正が残ります。今回の改善の中心は不要な変更の抑止であり、見逃しの解消ではありません。適用前に差分を確認してください。

詳しくは[変換UI](https://github.com/zenskypj/Komorebi-IME/blob/v0.3.0-rc.29-dev/docs/conversion-ui.md)と[校正・量子化評価](https://github.com/zenskypj/Komorebi-IME/blob/v0.3.0-rc.29-dev/docs/research/proofreading-evaluation.md)を参照してください。
