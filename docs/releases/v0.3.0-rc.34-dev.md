`0.3.0-rc.34-dev` のテスト用 APK です。**ユニバーサル debug 署名版**（`me.zssu.ime.debug`、versionCode 58）で、正式署名版ではありません。実機での操作確認は未実施です。

## rc.33-dev からの変更

- ユーザー辞書・追加システム辞書へ個別に登録・指定した語（および★の優先指定）がある読みでは、その語を先頭に保ち、AI 変換（zenzai-plus / Karukan）が越権しないようにしました。対象は利用者が個別に指定した内容に限り、Mozc 本来の語彙・予測・訂正や、指定のない読みでの AI 先頭表示・自動選択は従来どおりです。
- NFC で設定・学習を移行する機能の送受信を修正しました。送信側は画面を開いている間だけ HCE の対象 AID を優先サービスへ設定し、検出・完了を画面に表示します。受信側は reader mode に加えてフォアグラウンドディスパッチへフォールバックし、鍵生成を密着前に済ませ、転送を NFC コールバックとは別スレッドで行い、復元の受け入れが成功したときにだけ送信側へ完了を返します。
- 追加システム辞書を複数同時に有効化できるよう、生成側に value-trie id 上限（22bit→24bit）の緩和パッチと統合データセット（NEologd統合／SKK統合／全部入り）の生成を追加しました。統合データセットの実データは再生成後に提供するため、現行カタログでは単体辞書のみ選択できます。
- `:mozc` の lint タスクが生成済みランタイム資産を読むのに依存を宣言していなかった問題を修正し、`assembleRelease` と lint が通るようにしました。
