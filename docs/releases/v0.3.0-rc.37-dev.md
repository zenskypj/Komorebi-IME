`0.3.0-rc.37-dev` のユニバーサルdebug署名APKです（`me.zssu.ime.debug`、versionCode 61）。正式署名版ではありません。

## 変更

- rc.36の辞書統合・切り替え高速化・NFC修正・ドキュメントサイトを維持。
- 表記ゆれ辞書3 seedの全317,306行から、正規表記66,378組を作成し補正候補の順位へ使用。文面を機械的に置換せず、同音語や活用形を強制変更しない。
- カタカナ英語辞書を大量ユーザー辞書から読み完全一致の補助候補へ移動。旧コピーを除去し、英語語彙に引きずられた補正を抑制。個人辞書・★指定は維持。
- ★最優先はMozcの候補プール外でも補い、通常の辞書登録とAI2種より優先。非同期AIの返答時にも現在の★状態を再評価。同じAI表記との二重表示を防止。
- チャット送信などで入力欄が空になったことを次操作前にも確認し、未確定状態・候補・保留AI要求を破棄。古い候補タップの遅延イベントも無効化。
- PCの不要なGradle・Kotlin・辞書生成Bazel常駐を停止。APKビルドは並列1・Gradleヒープ上限2GiB・Kotlin同一プロセス・ビルド後常駐なしで実行。

## 作成条件

利用者の前の指定を継続し、追加の単体テスト・lint・実機確認は省略します。APKを作成できたことは、端末で不具合を解消したとの確認を意味しません。

追加辞書の既存配布先・ハッシュ・nativeランタイムは変更せず、大規模辞書の再ビルドはしていません。
