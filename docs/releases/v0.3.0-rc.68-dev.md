ツールから選択範囲を翻訳し、結果を見て置き換えられます。指やペンによる日本語の手書き、選択した画像の文字読み取りにも対応します。翻訳・手書き・画像読み取りは Google ML Kit の端末内処理です。

定型文の検索・並べ替え・差し込み、クリップボード履歴の検索・固定・個別削除、カーソルと範囲選択を拡張しました。候補を長押しすると、分かる範囲で出典を表示します。アプリ別の追加学習は初期オフで、アプリごとに消去できます。

きせかえは背景付きで保存・共有でき、ダークモード、時間帯、アプリごとに切り替えられます。性能診断は入力本文を含まないテキストファイルとして保存できます。

編集先への反映、認識品質、音声のマイク動作、実機上の速度とメモリは端末で未確認です。高速化率は未計測です。

今回の対象には、まだ実装途中の項目があります。入力中の独立した文節再分割、3エンジンの比較評価、スタイラス専用システム統合、キー位置ごとの画像測光などは引き続き対応が必要です。[対象別の実装状況](../research/input-roadmap-status.md)を参照してください。

配布する本体と音声モジュールは debug 署名のテスト APK です（それぞれ `me.zssu.ime.debug`、`me.zssu.ime.voice.debug`）。正式版アプリとは別にインストールされます。音声モジュールは v0.3.0 の既存ビルドです。
