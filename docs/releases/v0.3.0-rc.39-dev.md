`0.3.0-rc.39-dev` のユニバーサルdebug署名APKです（`me.zssu.ime.debug`、versionCode 63）。正式署名版ではありません。

## 変更

- フリックの削除キーを左へ動かすと、距離により「左の単語→行頭まで」を選択。上は「右の単語→行末まで」。
- 指を動かしている間は吹き出しへ操作名を表示し、離したときに1回だけ実行。先行する1文字削除や単語・行の連続削除を防止。
- 通常タップは離したときに1文字削除。中央の長押しは通常の連続削除を維持。開始後の移動は停止とし、単語・行削除へは移らない。
- 改行を越えず、行頭末尾は論理行の境界。選択があれば選択範囲だけ、未確定中はその中だけを削除し、変換中は読みに戻す。
- QWERTYと自作配列の既存方向割り当ては維持。取得不能な入力先や、取得範囲内に境界がない長文では範囲を推測して削除しない。
- アプリ内ガイド、docsの入力マニュアル・詳細仕様・FAQ・履歴・サイト索引を更新。rc.38の同梱固有名詞4,879語と従来の修正を維持。

## 作成条件

前の指定を継続し、追加テスト・lint・実機確認を省略。並列1・Gradleヒープ2GiB・CPU認識2・常駐なしでdebug APKを作成します。
端末ごとの区切りやエディタ動作・ジェスチャーの実用性は未検証です。native・大規模辞書の再生成はしません。
