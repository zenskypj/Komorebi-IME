## Liquid Glass の要件を Android へ

Apple の Liquid Glass は、光を曲げるナビゲーション層の素材です。今回の設定画面では、次の要件を Android 向けに翻訳しました。

- ガラスは上部バー・クイック操作バー・タブバーだけ。設定カードは不透明なコンテンツ面
- ガラスを重ねない。選択中のタブは単色のインジケーター
- 色付けは主操作と選択状態だけ
- 可読性のため、ガラス面に 1dp の境界線とスペキュラーハイライト、文字は不透明面
- コントラスト切り替えでガラス表現をオフにできる
- フローティングするタブバーと、ナビゲーションバーのインセット尊重

Android には iOS のような画面全体の屈折・レンズ効果を任意の Compose 画面へ適用する API がないため、半透明グラデーション、境界線、ハイライト、影、低彩度のアンビエント背景で表現しています。API 31 以降の `RenderEffect` も、背後のコンテンツをポータブルにサンプリングするものではありません。

## 新しい設定操作体系

- **5タブ**: ホーム、入力、変換、データ、情報。設定項目を目的別に絞り込む
- **横断検索**: タイトル・説明・キーワードから全設定を検索。結果にカテゴリを表示
- **二層のフッターバー**: ホームではクイック操作バー（キーボード・入力方法・検索・バックアップ）と5タブのフローティングタブバーを表示
- **ホーム**: キーボードの有効・選択状態、端末内処理の状態、よく使う設定、カテゴリショートカット
- **戻る**: 検索中は検索を閉じ、ホーム以外はホームへ。ホームでは画面を閉じる
- **設定詳細**: 既存の入力・変換・辞書・外観などの編集画面をそのまま開く
- **テーマ**: 設定専用の明暗パレット、Edge-to-edge、ステータス／ナビゲーションバーのアイコン色
- **アクセシビリティ**: 48dp以上のタブ、選択状態のsemantics、ラベル付きアイコン、コントラスト切り替え
