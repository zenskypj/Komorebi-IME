# Simejiの着せ替えとKomorebiの対応範囲

Simejiの[写真・動画きせかえ](https://simeji.me/blog/details/752)、[ボタンデザイン](https://app.simeji.me/blog/details/529)、[FAQ](https://simeji.me/faq)、[VIP機能](https://simeji.me/vip)、[操作ガイド](https://simeji.me/guide)を確認しました。公開記事には旧版やiOS向けの記述も含まれ、現在のAndroid実機での比較は行っていません。

| 項目 | 公式情報で確認した機能 | Komorebiで実装した範囲 |
| --- | --- | --- |
| 背景 | 写真・動画の位置やシーン指定、明るさ・ぼかし、複数枚のスライドショー | 写真1〜4枚、表示間隔、縦横位置、濃さ、明るさ、ぼかし、4フィルター。無音動画の再生範囲と縦横位置を設定 |
| キー | 枠の種類、グラデーションや破線、画像付きボタン、透明度 | 個別枠・塗りつぶし・仕切り線・枠なし・破線・グラデーション。文字キーと操作キーの素材を別々に指定。特定のキーだけ端末画像・色・枠・文字を変更 |
| ツールバー | 背景色とアイコン色 | 候補の配色と独立して設定 |
| 文字・ガイド | キートップ書体、フリックパーツと演出 | 4書体、太さ・大きさ・影・表示の個別指定。全方向・選択中のみ・非表示、ガイドの配色 |
| タップ・背景の演出 | タップ時と背景の演出、キー音と音量 | 波紋・きらめき、雪・光の粒、押下色・押下枠。キー音は標準音と合成3種類、合成音は音量調整可 |
| 入力エフェクト | 好きな画像とキーワードを組み合わせる | 最大8件。登録語を含む変換結果の確定時に画像を短く表示。機密欄やシークレット入力では再生しない |
| 素材・共有 | 公式のコラボ、VIPのAI切り抜き、AI画伯 | Komorebi独自の生成素材18点と完成テーマ9種。配列とテーマのJSON共有、端末画像は暗号化バックアップの対象。アプリ内のAI画像生成・自動切り抜き・配信ギャラリーは未実装 |

画面や項目名は[外観と配列](../manual/05-gaikan.md)を参照してください。追加した画像の生成手順は[素材の生成記録](keyboard-theme-art.md)に記載しています。
