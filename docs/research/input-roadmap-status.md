# 入力機能の実装と検証の範囲

対象は具体案の1、2の翻訳、3、4、5、7。実装順の番号とは別。

| 項目 | 今回の変更 | 残る作業 |
| --- | --- | --- |
| 1 変換 | 文脈の切り出し、内蔵辞書と個人登録の区別、表記の候補順位、アプリ別追加学習 | 入力中の独立した文節再分割、3エンジンの比較計測、物理フリックの追加補正 |
| 2 翻訳 | 原文・訳文の確認、置き換え、モデル取得・削除 | 各機種でモデル取得と編集先復帰の実測 |
| 3 操作 | 範囲選択・行移動、定型文の差し込みと検索、クリップボード検索と固定 | TalkBack・片手操作の端末確認 |
| 4 入力 | IME内の手書きパネル、画像OCRと結果編集、音声接続のタイムアウト・再試行 | システムスタイラス統合、音声・縦書きの実測 |
| 5 きせかえ | コントラスト、演出軽減、背景付きテーマ、時間・アプリ・ダークによる切替 | キー位置ごとの画像測光、キー専用画像ファイルの個別共有 |
| 7 診断 | 出典表示、アプリ別学習の削除、バックアップ対象案内、集計値の書き出し | 候補描画までの細分化、端末間の実際の復元確認 |

[変換の評価例](conversion-context.tsv) は手元の端末で文脈あり・なしを比較するための入力例で、実測結果ではありません。
