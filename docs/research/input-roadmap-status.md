# 入力機能の実装と検証の範囲

対象は具体案の1、2の翻訳、3、4、5、7。実装順の番号とは別。

| 項目 | 今回の変更 | 残る作業 |
| --- | --- | --- |
| 1 変換 | 文脈の切り出し、内蔵辞書と個人登録の区別、表記の候補順位、アプリ別追加学習 | 3エンジンの実機での比較計測と候補品質の評価 |
| 2 翻訳 | 原文・訳文の確認、置き換え、モデル取得・削除 | 各機種でモデル取得と編集先復帰の実測 |
| 3 操作 | 範囲選択・行移動、定型文の差し込みと検索、クリップボード検索と固定 | TalkBack・片手操作の端末確認 |
| 4 入力 | IME内の手書きパネル、画像OCRと結果編集、音声接続のタイムアウト・再試行 | システムスタイラス、音声・縦書きの実測 |
| 5 きせかえ | コントラスト、演出軽減、背景付きテーマ、時間・アプリ・ダークによる切替 | 動画背景の位置別測光、画像の見やすさの実測 |
| 7 診断 | 出典表示、アプリ別学習の削除、バックアップ対象案内、集計値の書き出し | 端末間の実際の復元確認 |

[変換の評価例](conversion-context.tsv) は手元の端末で文脈あり・なしを比較するための入力例で、実測結果ではありません。

rc.69 では独立セッションによる文章候補、フリックの入力候補、システムスタイラス、写真の位置別文字色と画像付き配列の共有を追加。3エンジンの結果を揃えて比較するスクリプトは `scripts/compare_conversion_results.py`。数値は実機測定まで未確定。
