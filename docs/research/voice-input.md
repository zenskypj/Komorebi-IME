# 任意の音声入力モジュール

本体とは別 APK。利用者が Vosk の [日本語 small モデル](https://alphacephei.com/vosk/models) `vosk-model-small-ja-0.22`（Apache-2.0）を明示的にダウンロードし、音声認識は端末内で行う。圧縮データ 49,704,573 バイト、展開データ 98,852,853 バイト。取得時は両方と一時領域を保存できる空き容量が必要。配布物の SHA-256 は `efa092d280153a77615e9e0c7d7283e93e600de3d19d3bec686c57ef19d52eac`。Vosk の一般的な small モデルについて、公式は実行時メモリ約 300 MB と説明している。端末での測定値ではない。

Vosk Android 0.3.75 と JNA 5.18.1 を使用。同一署名の本体のみが呼び出せるバインドサービスを使い、録音中の状態と認識結果をキーボードに表示する。キーボードを閉じる・入力先を離れる・文字キーを押すと録音を停止する。マイク権限はモジュールだけが要求する。モデル取得時以外にネットワークを使用せず、録音や入力中の本文を送信しない。

日本語認識精度、待ち時間、実メモリ消費、実際の入力先への復帰、16 KB ページ端末での動作は端末未接続のため未検証。
