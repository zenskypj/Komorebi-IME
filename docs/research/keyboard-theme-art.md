# 着せ替え素材の生成記録

組み込みの OpenAI ImageGen で、背景9点とキー素材9点を個別に生成しました。Simejiの素材は使っていません。APKでは `app/src/main/assets/theme-art/` に入った WebP を使います。背景は横幅960px、キー素材は横幅256pxに縮小しており、利用時に画像を生成したりダウンロードしたりする必要はありません。

[素材18点の一覧画像](../assets/keyboard-theme-contact.jpg)
