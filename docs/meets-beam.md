# Meets Beam（実験的）

Komorebi IME の設定で両端末とも Meets Beam を有効にし、NFC をオンにする。
送信側はキーボード上部の Meets Beam アイコンから「送信側になる」を選ぶ。
受信側は同じ画面で「受信側になる」を選ぶか、Komorebi の設定画面などを前面に開く。
送信側には Android の NFC カードエミュレーション（HCE）が必要。

- ブラウザ: オプションのユーザー補助を有効にすると、送信操作時に対応ブラウザの
  アドレス欄から URL を取得する。取得できない場合はブラウザの共有メニューから送る。
- アプリ: 編集欄のアプリを送る。受信画面から起動でき、未インストールの場合は Play ストアを開く。
- テキスト: Android の文字選択メニュー「Meets Beam で送る」または共有メニューから送る。
  受信内容はクリップボードにコピーする。テキストは最大 32 KiB。
- 辞書パック: ユーザー辞書画面の「Beam」ボタン、または共有メニューから送る。
  受信内容を確認し、「置き換える」を選んだときだけユーザー辞書を置き換える。
- ファイル・大容量データ（rc.44）: 共有メニューから画像・動画・音楽・ドキュメントを送る。
  NFC で一時トークンと端末名を交換し、Wi-Fi Direct（P2P）の標準手順で相手を検出して接続する。
  グループオーナーは自動決定し、どちらの端末がなっても GO が待ち受け、クライアントが
  49152〜49161 のポートを探索して接続する。平文は AES-GCM で暗号化し、宣言サイズと
  SHA-256 を照合する。受信ファイルはアプリ専用領域に保存し、「ファイルを開く／共有」から開く。
  端末同士の直接通信のみを使用し、クラウドや外部サーバーは一切経由しない。
- 権限: Android 13 以降は近接端末、Android 12 以下では位置情報の権限を Wi-Fi Direct の
  検出だけに使う。位置の記録・送信は行わない。Android 13 以降でも、端末の位置情報モードは
  オンにする必要がある（アプリは位置情報を取得しない）。
- 端末アドレスを取得できない端末では、端末名で相手を照合し、検出したピアが1台だけなら
  その端末へ接続する。NFC の接続情報は端末アドレスなしでも送れる。

暗号化して直接送信し、クラウドに送らない。相手端末の本人確認は行わないため、
信頼できる端末同士で操作する。ユーザー補助は初期状態では無効であり、許可した場合も
送信操作時だけ対応ブラウザの URL 欄を参照する。Android やブラウザの仕様により
URL 欄を取得できない場合がある。NFC 実機 2 台・各ブラウザでの検証は未実施。
Wi-Fi Direct の実機 2 台での接続・転送も未検証である。

NFC の送信サービスを起動できなかった場合は、送信待ちに進まずエラーを表示します。ファイルや辞書の送信側は接続情報を渡した後も転送完了まで待機します。中止した場合は、再度送信側・受信側を選び直してください。
