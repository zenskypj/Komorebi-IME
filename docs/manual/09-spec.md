# 詳細仕様

この章は、ふだん使ううえでは知らなくても困らない**細かい仕様と制約**をまとめた付録です。各章の「補足」はここへ集約し、必要な箇所から参照します。

## 技術仕様

| 項目 | 値 |
| --- | --- |
| application ID（正式） | `me.zssu.ime` |
| application ID（debug） | `me.zssu.ime.debug` |
| minSdk / targetSdk | 24 / 36 |
| ネイティブ | Mozc（BSD 3-Clause）を組み込み。`libmozc.so`（4 ABI） |
| 変換基盤 | Kotlin ラッパー（`MozcEngine` / `MozcSession`）経由で JNI を扱う |
| 入力方式 | かな/英字フリック、かな/英字 QWERTY、混在、かなだけ QWERTY |
| 権限 | `INTERNET`（任意取得・更新確認）、`ACCESS_NETWORK_STATE`、`RECEIVE_BOOT_COMPLETED`、`POST_NOTIFICATIONS`、`NFC`、Wi-Fi Direct、Android 12 以下の位置情報。詳細は下記「権限」参照 |
| クラウドバックアップ | 無効 |

### 権限

| 権限 | 用途 | 条件 |
| --- | --- | --- |
| `INTERNET` | モデル・辞書取得、絵文字・アプリ更新確認 | アプリ更新の自動確認は初期状態でオン。設定から停止可能 |
| `ACCESS_NETWORK_STATE` | 自動確認時のネットワーク接続条件 | 更新の定期確認 |
| `RECEIVE_BOOT_COMPLETED` | 更新確認ジョブを再起動後も維持 | 自動確認がオンのとき |
| `POST_NOTIFICATIONS` | 新しいリリースの通知 | Android 13 以降は利用者が許可したとき |
| `NFC` | Meets Beam、NFC による設定・学習の移行 | 利用者が有効化して送受信を選んだときだけ |
| `ACCESS_WIFI_STATE` / `CHANGE_WIFI_STATE` / `NEARBY_WIFI_DEVICES` | Wi-Fi Direct のグループ作成・検出・接続 | Meets Beam の大容量転送時だけ |
| `ACCESS_FINE_LOCATION` / `ACCESS_COARSE_LOCATION` | Wi-Fi Direct の端末検出（Android 12 以下） | `maxSdkVersion=32`。位置の記録・外部送信はしない |

> [!NOTE]
> AndroidX が非公開ブロードキャスト受信用の署名権限 `DYNAMIC_RECEIVER_NOT_EXPORTED_PERMISSION` を自動宣言します。ユーザーの許可は不要で、外部アプリには付与されません。
>
> Wi-Fi Direct の `discoverPeers` / `requestPeers` は、Android 13 以降でも端末の位置情報モードがオンのときだけ動作します。アプリは位置情報を取得・送信しません。

## 削除フリックの仕様（rc.39）

| 項目 | 内容 |
| --- | --- |
| 適用 | フリック系入力方式で、方向操作が未割り当てのBackspaceキー |
| 操作 | 左：後方単語→行頭、上：前方単語→行末 |
| 近い段階 | 通常のフリック閾値以上 |
| 遠い段階 | フリック閾値×2.5と64dpの大きい方以上 |
| 安定化 | 遠い段階から戻す判定に20%の余裕、方向の切り替えにも余裕を設ける |
| 実行 | 離したとき1回。タップも離したとき。中央の長押しは通常の連続削除 |
| 境界 | 端末の日本語word break。UTF-16サロゲートを分断しない。改行を越えない |
| 行 | LF・CR・Unicode行/段落区切りで区切る論理行。画面上の折り返しは含まない |
| 選択範囲 | 選択があればそこだけを削除（選択内の改行も対象） |
| 未確定 | 変換は読みに戻し、その未確定範囲内を操作。全削除時も未確定以外には触れない |
| 入力先への照会 | 前後最大8,192 UTF-16単位。目的の境界が取得範囲外なら部分削除を推測しない |
| 取得不可 | 単語・行削除をしない。通常Backspaceは既存動作を維持 |

実機でのジェスチャー・日本語の区切り・端末欄との互換性は未確認です。

## 補足：この文書での「補足」の扱い

このマニュアルでは、補足・制約を次の 3 層に分けて扱います。

| 層 | 置き場所 | 用途 |
| --- | --- | --- |
| 局所的な注意 | 各章のコールアウト（NOTE / TIP / IMPORTANT / WARNING） | その操作の直前に知るべき前提・落とし穴 |
| 横断的な仕様 | この「詳細仕様」章 | 複数の章から参照される数値・制約・実装 |
| 変更履歴 | [リリースノート](https://github.com/zenskypj/Komorebi-IME/tree/main/docs/releases) | 版ごとの追加・修正 |

原則:

1. **must（守らないと困る）と nice（知ると得）を分ける**。must は IMPORTANT / WARNING、nice は NOTE / TIP。
2. **1 か所に書いて、他から参照する**。同じ注意を各所へ複製しない（重複は必ず食い違う）。
3. **アンカーで指せる**。見出しは安定した ID を持ち、他章から `#既知の制約` のように参照できるようにする。
4. **版で錆びる数値は出典へリンクする**。サイズ・SHA-256・語彙数はリリースのカタログ／報告を正とする。

## 英語候補の順位（rc.41）

かなの読みから英字のみの表記になる候補は、Nativeのシステム／ユーザー辞書属性にかかわらず日本語候補の後ろへ安定分割します。全角英字も判定します。予測・変換一覧・かな表記補充後・完全一致の辞書優先処理に適用。Native IDと各群の相対順は維持します。★完全一致、個人登録と確認できた候補、固有名詞の未完成の先読みは除外。AI自体の通常優先と英字直接入力は変更しません。辞書別出典がAPIにないため文字種による判別で、混在表記には適用しません。

## 入力応答の軽量化（rc.42）

キーの押下表示・フリックガイドに待ち時間付きのアニメーションはありません。従来はMozcの変換と描画が同じUIスレッドで走り、変換待ちがキー表示の遅れにもつながる構造でした。今回、次を削減しました。

- QWERTY・Godan・単純な数値パッドでは、フリック連打用の余分なMozcコマンドを送らない。
- フリックと数字／記号のトグル配列では連打・濁点・小文字に必要な処理を残し、表示しない中間候補の組み立てを省略。
- 1入力でNative候補と補助候補を続けて描き直す経路を1回へ。補助候補がない場合の重複順位付けも省略。AIが後から結果を返した場合の更新は維持。
- 2行候補とツールバーを再利用し、同じ文字・★アイコン・背景への不要な再設定を削減。
- Android 12以降で送信後の空欄を確認するときは小さな周辺テキストを先に取得。未対応の入力先・旧APIは抽出テキストへフォールバックし、短い取得量を要求。入力先が要求を無視する場合は全文が返ることがあります。

入力文字を間引いたり、候補行数や先読みを無効にする変更ではありません。Mozcの初期化・変換・文節操作・候補確定・設定反映は専用の直列ワーカーへ移しました。入力欄・Viewの操作はUIスレッドへ戻します。実機がないため、改善率・遅延・FPS・連打や入力先の互換性は未測定です。

### 非同期Mozcの順序と入力先の保護

同じ入力先の文字・削除・変換・確定は受付順に処理し、文字キーを間引きません。Nativeを複数同時に呼ぶ方式ではありません。待機中に配列が変わっても、各文字キーは押したときの配列・機密欄／補正／トグル設定を保持します。

入力先の終了・別欄への移動・外部での本文消去では、古い未処理イベントと結果を破棄し、新しい欄への混入を防ぎます。実行中のJNIを強制終了するのではなく、完了結果を受け取らず、その後の同一ワーカーでリセット・次の入力を進めます。同じ欄の再起動では順番を保ちます。

入力イベントと候補はメモリ内のみで処理します。任意の入力性能記録は、キー受付から待ち行列・Native処理・UI更新処理完了までの集計値です。実際のフレーム表示時刻やCPU時間ではありません。入力先アプリへのテキスト問い合わせや画面の計測・描画はUI側に残るため、あらゆる遅延がなくなる保証はありません。

長押しの自動リピート（削除・カーソル移動など）は、待機／実行中を合わせて1イベントまでに抑えます。指を離すと未実行分を取り消し、最初の通常押下は保持し、自動反復は既に受け付けて実行中の1回だけ完了します。Native処理が遅いときに削除や移動が大量に溜まって後から続くことを防ぎます。通常の物理打鍵や指の移動量に対応する操作は間引きません。

## アプリ更新の確認

`JobScheduler` がネットワーク接続を条件におおむね24時間ごとに GitHub Releases の直近100件を取得します。再起動後もジョブを維持しますが、省電力制限・通信状況により実行時刻は保証しません。設定から停止でき、手動確認も可能です。候補は公開済みで解析可能なタグに限り、RC の番号を数値として比較します。正式版と RC はそれぞれ保持し、`0.3.0-rc.57-dev` より `0.3.0` を新しい版として扱います。GitHub の prerelease フラグが過去の RC 表記と一致しない場合もタグに基づいて判断します。ページを開いて利用者がインストールする方式で、APKの自動取得・自動インストールはしません。
