# 辞書

Komorebi IME の辞書は、目的の違う 4 種類があります。混同しやすいので最初に整理します。

| 種類 | 何のため | 追加方法 | 変換への関与 |
| --- | --- | --- | --- |
| 同梱辞書 | アプリに入っている固有名詞・用語 | APKの更新。追加取得は不要 | 有効な辞書の語を変換候補へ追加 |
| ユーザー辞書 | 自分の語を登録 | GUI・TSV 入出力 | 変換候補（最優先指定も可） |
| 追加システム辞書 | 大規模語彙（NEologd / SKK） | 明示ダウンロード | 標準辞書と同じ枠で変換に参加 |
| 意味辞書 | 語の意味を表示 | JSON 取り込み | 候補の並びには関与しない（長押し表示のみ） |

## ユーザー辞書

設定の「ユーザー辞書」から、読み・単語・品詞を登録します。正本は Mozc / Google 日本語入力の辞書ツールと互換の **TSV** として管理し、端末上では暗号化して保存します。

| 操作 | 内容 |
| --- | --- |
| 追加・編集・削除 | GUI から。読み・単語・品詞を指定 |
| 取込 | Android のファイル選択画面から TSV を取り込む（**現在の辞書を置き換え**） |
| 書出 | 現在の辞書を TSV で書き出す |

取り込み前に TSV の形式とサイズを検証し、同じ読み・単語の重複を整理してから暗号化保存します。

> [!TIP]
> 品詞に「サジェストのみ」を選ぶと、変換候補ではなくサジェストに限定できます。

## 同梱辞書（追加ダウンロード不要）

「変換エンジン・辞書」→「変換辞書の切り替え」で、固有名詞とAI・テクノロジー辞書を個別に切り替えます。
初期状態では有効です。無効にした辞書は、アプリ更新後も無効のままです。
ネット辞書の取得や、自分のユーザー辞書へのファイル取り込みは必要ありません。

| 辞書 | 内容 | 出典・ライセンス |
| --- | --- | --- |
| 有名固有名詞 | 人名・地名・組織・企業・サービス名など **4,879語**（rc.38） | 同梱NOTICEと[原本・統合記録](https://github.com/zenskypj/Komorebi-IME/tree/main/data/dictionaries) |
| AI・テクノロジー | AI企業・技術用語・スタートアップ名 | 同梱NOTICE |
| カタカナ→英語 | [google-ime-user-dictionary-ja-en](https://github.com/KEINOS/google-ime-user-dictionary-ja-en)由来。**読みが完全一致したときだけ**補助候補に表示。誤入力補正には使わない | CC BY-SA 3.0 |

### rc.38で追加した固有名詞

利用者提供のJSONL **4,468件**を、従来の固有名詞辞書へ合併しました。
既存側の重複15行と、追加分との重複106語を整理し、**合計4,879語・純増4,362語**です。
人名・地名・組織を区別しています。

使うにはrc.38以降のAPKへ更新し、「有名固有名詞」を有効にします。
アプリ起動後、同梱データをバックグラウンドでMozcへ取り込みます。この処理にネットワークは使いません。
JSONLを別に取り込んだり、NEologd・SKKのネット辞書を取得したりする必要はありません。

この合併では、利用者が「ユーザー辞書」で登録した語や学習履歴は置き換えません。
提供JSONLの`cost`は原本に保存していますが、既存の取り込み形式では語ごとの順位コストに適用できません。
数値と制約は[詳細仕様](09-spec.md)に記録しています。

元データ・帰属表示は保持し、追加データに従来分のCC0を自動適用しません。
出典の詳細は同梱NOTICE、[原本・再生成手順](https://github.com/zenskypj/Komorebi-IME/tree/main/data/dictionaries)を参照してください。

## 固有名詞・登録語の途中一致予測

rc.40から、同梱固有名詞・AI用語と個人辞書・★登録語は、読みが完全に一致する前から候補に入ります。通常は2文字以上を入力し、前方一致した読みの進み具合やMozc順位・学習により段階的に上位へ出します。

追加ダウンロードは不要です。入力ごとに辞書全体を走査せず、端末内の索引を使います。抑制単語はこの補助予測から除外します。

カタカナ語→英語辞書の途中一致は今回の対象外です。先読み・補正・AIとの優先関係は[変換と候補](02-henkan.md)を参照してください。

## 追加システム辞書（ネット辞書）

「変換エンジン・辞書」から、NEologd / SKK の大規模辞書を明示的に取得して使います。追加語もシステム辞書として文章変換に参加します。一度に使うのは 1 データセットです。

### 収録データセット

| データセット | 元データ | ライセンス |
| --- | --- | --- |
| NEologd 新語・固有名詞 | mecab-user-dict-seed 全行 | Apache-2.0 |
| NEologd 表記ゆれ・活用語 | その他 11 seed 全行 | Apache-2.0 |
| SKK 総合・人名・地名・専門語 | GPL 系公式個別辞書 | GPL-2.0 |
| SKK 英和 | edict・edict2 | CC BY-SA 3.0 |
| SKK 絵文字・異体字 | emoji・ivd | Unicode License |
| SKK 沖縄・郵便番号・異体字・pubdic+ | okinawa・zipcode など | PD / Pubdic+ |

### 複数辞書の同時有効化（統合データセット）

「使う辞書を選ぶ」で複数をチェックすると、選択したすべてを含む**統合データセット**が使われます。

| 統合データセット | 含む単体辞書 | 保存 | 取得 |
| --- | --- | --- | --- |
| NEologd 統合 | NEologd 新語・固有名詞＋表記ゆれ・活用語 | 78.4 MiB | 47.6 MiB |
| SKK 統合 | SKK 4 種 | 25.9 MiB | 17.3 MiB |
| 全部入り | 上記 6 データセット | 85.6 MiB | 51.9 MiB |

<small>表示サイズはユニバーサル版の目安です。実際の値はアプリ内の表示とリリースのカタログを参照してください。</small>

| 選択 | 使われるデータセット |
| --- | --- |
| 1 つだけ | その単体辞書 |
| NEologd 2 種 | NEologd 統合 |
| SKK 4 種 | SKK 統合 |
| 別系統をまたぐ（例: NEologd＋SKK） | 全部入り |

- 入力欄を離れ、未確定文字列がなくなってから切り替えます。キーボードを隠しただけでは待機します。
- 取得は HTTPS のみ。圧縮前後のサイズ・SHA-256・Mozc magic・アプリ同梱ランタイムの指紋を確認し、一時ファイルへ展開してから置き換えます。
- 取得先へ入力内容・個人辞書・学習履歴を送信しません。標準辞書へ戻した後に削除できます。

> [!NOTE]
> 同時に有効化できるのは 1 つのデータセットです。統合データセットはその内部に複数の辞書を含みます。導入済みデータ・圧縮ファイル・展開中ファイルのぶん、追加の空き容量が必要です。

## 意味辞書（JSON）

Mozc の変換辞書とは分離した JSON です。設定から取り込み、ひな形の書き出し、削除ができます。

```json
{
  "id": "my_dictionary",
  "label": "自分の意味辞書",
  "entries": [
    {
      "term": "木漏れ日",
      "reading": "こもれび",
      "meanings": ["木々の葉の間から差し込む日光。"],
      "tags": ["名詞"],
      "source": "自作"
    }
  ]
}
```

| 項目 | 内容 |
| --- | --- |
| 照合 | 候補の表示文字列と `term` の**完全一致** |
| 出所 | 問わない（Mozc 標準・同梱・ユーザー辞書・学習履歴のどれでも一致すれば表示） |
| 表示 | 候補の長押し |

> [!NOTE]
> Mozc の語彙データそのものには国語辞典の意味情報が含まれないため、未登録語の意味が自動生成されることはありません。活用形から基本形を推測することもありません。

追加システム辞書の収録方針・再生成手順は[追加辞書の収録範囲・制限](/docs/extra-dictionaries/README.md)を参照してください。

## 英語候補の表示順位（rc.41）

内蔵・ダウンロード辞書の英語候補は、かな読みが完全一致しても日本語候補より後ろへ表示します。候補は残し、明示的な★指定は維持します。[変換と候補](02-henkan.md)を参照してください。
