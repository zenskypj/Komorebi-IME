# プライバシーとセキュリティ

Komorebi IME は「オフライン・最小権限」を方針にしています。入力内容を端末の外へ送らないことが最優先です。

## 送信するもの／しないもの

| 送信する | 条件 |
| --- | --- |
| 公開モデルのダウンロード | 利用者が設定画面で開始したときだけ（Karukan / zenzai-plus / AI 文章校正） |
| 追加システム辞書の取得 | 利用者が「取得する」を押したときだけ（GitHub Releases） |
| アプリ更新の確認 | 初期状態で有効。おおむね1日1回、GitHub Releases の公開情報を取得。設定で停止可能 |
| 絵文字データの更新確認 | 絵文字一覧を開いたとき、最大 30 日に 1 回（Unicode.org） |

| 送信しない | 内容 |
| --- | --- |
| 入力内容・変換候補 | 一切送信しません |
| 周辺文脈 | 推論は端末内で行われます |
| 変換学習履歴・ユーザー辞書 | 端末内のみ |
| 背景の写真・動画、キー画像、着せ替え設定 | 端末内のみ。明示したバックアップ・移行でのみ持ち出し |

> [!IMPORTANT]
> 広告 SDK・解析 SDK・クラッシュレポート SDK は組み込んでいません。要求する権限は、任意取得・更新確認用の `INTERNET`、接続状態を確認する `ACCESS_NETWORK_STATE`、再起動後も自動確認を維持する `RECEIVE_BOOT_COMPLETED`、更新通知用の `POST_NOTIFICATIONS`、Meets Beam・NFC 移行用の `NFC`、Wi-Fi Direct 用の `ACCESS_WIFI_STATE` / `CHANGE_WIFI_STATE` / `NEARBY_WIFI_DEVICES`、Android 12 以下に限り Wi-Fi Direct 検出用の `ACCESS_FINE_LOCATION` / `ACCESS_COARSE_LOCATION` です。位置情報は端末の検出だけに使い、位置の記録・外部送信は行いません。Android 13 以降でも Wi-Fi Direct の検出には端末の位置情報モードをオンにする必要がありますが、アプリは位置情報を取得しません。

別途導入する音声入力モジュールは `RECORD_AUDIO` を要求し、利用者の操作と許可後にマイク用フォアグラウンドサービスと通知を使ってマイクを使い、キーボードを閉じたときなどは録音を停止します。また `INTERNET` 権限を使い、利用者が明示したときだけ公開元から日本語モデルを取得します。音声や入力内容を送信せず、認識は取得済みモデルで端末内で行います。確認した結果だけを同一署名の IME に渡し、録音と結果をモジュール内のファイルには保存しません。

## 端末間の Wi-Fi Direct

Meets Beam の大容量転送は、NFC で交換した接続情報を使って端末同士を Wi-Fi Direct で直接接続します。クラウド・外部サーバーは経由しません。転送は AES-GCM で暗号化し、宣言サイズと SHA-256 を検証します。受信したファイルはアプリ専用領域に保存し、利用者が開く・共有するまで外部アプリへ渡しません。辞書は内容を確認し、「置き換える」を選んだときだけユーザー辞書を置き換えます。

## 端末内に保存するデータ

| データ | 保存方法 |
| --- | --- |
| GUI のユーザー辞書 | AES-GCM + Android Keystore |
| Mozc のユーザー辞書 | Keystore 由来の鍵で暗号化 |
| Mozc の変換学習履歴 | Keystore 由来の鍵で暗号化 |
| 最優先候補（★）の読みと表記 | AES-GCM + Android Keystore |
| zenzai-plus の TTT 学習チェックポイント | AES-GCM + Android Keystore |
| 定型文 | Keystore 由来の鍵で暗号化 |
| クリップボード履歴（最大 20 件） | メモリ内のみ（プロセス終了で消去） |
| アプリ別プロファイルと入力先パッケージ名 | アプリ専用領域の JSON |
| 最近使った絵文字・顔文字、お気に入り | アプリ専用 SharedPreferences |
| 追加した意味辞書 | アプリ専用領域の JSON |
| Karukan / zenzai-plus / 校正モデル | アプリ専用領域（設定から削除可能） |
| Meets Beam の受信ファイル | アプリ専用領域 `files/beam/`（辞書は読み込み後に削除） |
| Android のクラウドバックアップ | 無効（`allowBackup=false`） |

## 暗号化の仕組み

- 鍵は **Android Keystore** が保持します。セキュアエレメントを持つ端末では抽出できません。
- Mozc の Linux 版は鍵を保護対象と同じディレクトリへ平文で書いてしまうため、Android 用の分岐を追加して Keystore の鍵を Java から注入しています（[設計の詳細](/docs/profile-encryption.md)）。
- 平文鍵や未暗号の辞書が過去ビルドに存在した場合は、読み込んで移行し、その後暗号化して保存し直します。

> [!NOTE]
> これは Android の端末暗号化を置き換えるものではありません。OS の全ディスク暗号化に加えて、バックアップ・ロック解除済み端末の検査・debug ビルドの `adb pull` に対する保護を足すものです。Keystore の安全性は端末の実装に依存します。

## データの削除

Android の設定から本アプリのストレージを消去するか、アンインストールすると、本アプリが端末内に保存したデータは削除されます。Android や端末メーカーが管理する領域の動作は、それぞれの仕様に従います。

| 消したいもの | 手順 |
| --- | --- |
| 変換学習 | 設定の学習リセット |
| 個別の学習候補 | 候補を長押し→「学習削除」 |
| ユーザー辞書 | 「ユーザー辞書」から編集・削除 |
| 追加システム辞書 | 標準辞書へ戻す→「削除」 |
| 意味辞書 | 設定から削除 |
| モデル | 「変換エンジン・辞書」から削除 |
| すべて | Android 設定でストレージ消去、またはアンインストール |

## 全文

公開プライバシーポリシーは [PRIVACY.md](https://github.com/zenskypj/Komorebi-IME/blob/main/PRIVACY.md) にあります。アプリ内の「プライバシー」表示と内容を一致させています。

## 登録語の先読み

固有名詞・個人辞書・★登録語の索引は端末のメモリ内に準備し、入力や索引を外部へ送りません。補助候補の選択が入力欄へ適用されたときは、語の完全な読みで既存のMozc学習履歴へ追加します。機密欄・学習禁止欄ではこの追加記録をしません。

「変換学習」でアプリ別の追加学習と性能診断を必要に応じて有効にできます。追加学習はアプリ単位で削除できます。性能診断は、入力本文・候補・クリップボード・アプリ名を含めず、画面表示とファイル保存ができます。
