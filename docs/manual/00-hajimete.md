# はじめての Komorebi IME

Komorebi IME は、Android 向けのオープンソース日本語入力（IME）です。[Mozc](https://github.com/google/mozc) をアプリ内に組み込み、**入力内容を端末の外へ送らない**ことを最優先に設計しています。

名前は「木漏れ日」に由来します。入力という反復作業を、そっと照らす道具でありたいという意味です。

> [!TIP]
> **まずは使ってみる** — 最新版は [GitHub Releases（latest）](https://github.com/zenskypj/Komorebi-IME/releases/latest) から取得できます。テスト用 APK は debug 署名（`me.zssu.ime.debug`）で、正式版とは別アプリとして共存します。

## 30秒でわかる特徴

| 特徴 | 内容 |
| --- | --- |
| オフライン変換 | Mozc をネイティブ組み込み。変換は完全に端末内で完結します |
| 入力は端末内 | 入力・文脈・辞書・学習履歴を外部へ送信しません |
| 4つの入力方式 | かな・英字ともフリック／ともにQWERTY／英字だけQWERTY／かなだけQWERTY |
| 誤入力補正 | フリックずれ・促音脱落・重複・隣接転置をルールベースで補正 |
| AI 変換（任意） | zenzai-plus / Karukan のニューラル変換を端末内で実行 |
| AI 文章校正（任意） | Qwen3.5 0.8B / Qwen3 1.7B / Gemma 4 E2B で端末内校正 |
| 辞書 | ユーザー辞書（GUI・TSV入出力）、追加システム辞書（NEologd/SKK）、JSON 意味辞書 |
| 暗号化 | 辞書と学習履歴は Android Keystore の鍵で保存時に暗号化。クラウドバックアップ無効 |
| カスタマイズ | 配列・テーマ・背景・キーの高さ・片手モード・アプリ別プロファイル |

## 対応環境

| 項目 | 対応 |
| --- | --- |
| OS | Android 7.0（API 24）以上 |
| CPU | `arm64-v8a` / `armeabi-v7a` / `x86_64` / `x86` |
| AI 変換（zenzai-plus / Karukan） | 現在 `arm64-v8a` のみ |
| AI 文章校正 | `arm64-v8a` のみ |
| 権限 | `INTERNET`（任意取得）、`NFC`（Meets Beam/移行）、Wi-Fi Direct、Android 12 以下の位置情報（検出のみ） |
| クラウドバックアップ | 無効（`allowBackup=false`） |

> [!NOTE]
> Wi-Fi Direct の検出には、Android 13 以降でも端末の位置情報モードをオンにする必要があります（アプリは位置情報を取得しません）。
>
> 現在は正式版に向けた Release Candidate（`0.3.0-rc.x`）です。テスト用 APK はすべて debug 署名で、正式署名版ではありません。

## インストールと初期設定

1. **インストール** — [GitHub Releases](https://github.com/zenskypj/Komorebi-IME/releases) から APK を取得して開きます（提供元不明アプリの許可が必要な場合があります）。
2. **アプリを起動** — 「Komorebi IME」を開きます。
3. **キーボードを有効化** — 「キーボードを有効化」→ 設定画面で Komorebi IME をオンにします。
4. **キーボードを選択** — 「キーボードを選択」→ Komorebi IME を選びます。
5. **試し入力** — 設定画面の「入力の使い方」を開き、練習欄で変換できることを確認します。
6. **（任意）入力方式を選ぶ** — 初回は「かなフリック / QWERTY / 英字だけ QWERTY / かなだけ QWERTY」から選びます。

初回起動やアプリ更新後は、同梱の固有名詞・AI用語辞書をバックグラウンドで取り込み、英語の完全一致候補も準備します。**この処理にネットワークは使いません。** rc.38の固有名詞4,879語もAPKに含まれ、追加取得は不要です。有効・無効は「変換エンジン・辞書」の「変換辞書の切り替え」で選べます。詳しくは[辞書](04-jisho.md)を参照してください。

| やりたいこと | 手順 |
| --- | --- |
| AI 変換を使う | 「変換エンジン・辞書」→ Karukan モデルを取得、または zenzai-plus を有効化 |
| AI 文章校正を使う | 「変換エンジン・辞書」→ AI 文章校正モデルを取得 |
| 同梱の固有名詞を使う | 「変換エンジン・辞書」→「変換辞書の切り替え」→「有名固有名詞」をオン |
| ネット辞書を追加 | 「変換エンジン・辞書」→ 追加システム辞書を取得 |
| 単語を登録 | 「ユーザー辞書」→ 読み・単語・品詞を追加 |

> [!IMPORTANT]
> application ID がフォーク元と異なる（`me.zssu.ime`）ため、Android 上では別アプリとして共存します。フォーク元や旧 `dev.oss.ime` ビルドの設定・学習履歴・ユーザー辞書は自動移行されません。

## 最初の1週間で覚えること

- 変換は **変換キー**（QWERTYではスペース）。1回押すと文節へ自動分割されます。
- 変換1回目の後は **左右キーで文節移動**。もう一度変換して候補選択に入ると、左右キーで区切りを縮小・拡大できます。候補欄の「∨」→「文節を調整」からボタンでも操作できます。
- 候補は **タップで確定**、**長押しで意味・最優先登録・学習削除**。
- 候補領域は候補がないとき **ツールバー**になり、片手モード・絵文字・設定へ移動できます。
- 困ったら **設定 → 入力の使い方** に図解付きの練習画面があります。
