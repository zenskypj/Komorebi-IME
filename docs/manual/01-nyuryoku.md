# 入力方式と基本操作

## 入力方式

設定の「入力方式」から次の 4 つを選べます。初回起動時にも選べます。

| 方式 | かな | 英字 | 向いている人 |
| --- | --- | --- | --- |
| かな/英字ともフリック | フリック | フリック | ケータイ入力に慣れている |
| かな/英字とも QWERTY | QWERTY | QWERTY | PC と同じ操作で統一したい |
| かなフリック＋英字 QWERTY | フリック | QWERTY | 日本語はフリック、英字は QWERTY |
| かなだけ QWERTY | QWERTY | QWERTY | ローマ字入力派 |

「かなフリック＋英字 QWERTY」では、英字面の左下が常に「かな」切り替えになり、切り替え位置が統一されます。

| 操作 | 動き |
| --- | --- |
| フリック | キーを押して方向へ払う。中央は主文字 |
| 記号面の切り替え | `1/2`・`2/2` キー。2 ページ目に括弧・引用符・比較/演算・矢印・プログラミング記号 |
| 濁点・半濁点・小書き | 該当キーの長押し／フリックで切り替え |
| 英字 QWERTY 上段の長押し | `1`〜`0` を直接入力（`longPress` でカスタム可） |
| フリックの連打 | 設定で「フリックのみ」「フリック＋ケータイ打ち」を選択 |

> [!TIP]
> ケータイ打ちでは、約 0.65 秒待つか右方向キーで文字を区切り、同じキーを続けて入力できます。

## カーソルと編集

| 操作 | 動き |
| --- | --- |
| 未変換中にスペースを左右フリック | 未確定文字列内のカーソルを 1 文字移動 |
| スペース長押し→左右ドラッグ | トラックパッドのように連続移動（中心付近で停止、離れるほど速い） |
| 変換中に左右キー | 対象文節を移動 |
| 変換中にスペース左右フリック | 選択文節の境界を縮小・拡大 |
| 変換中の文節バーをタップ | その文節を選択 |
| フリック削除キーを左へ | 近く：左の単語を削除、遠く：行頭まで削除 |
| フリック削除キーを上へ | 近く：右の単語を削除、遠く：行末まで削除 |
| Backspace 長押し | 中央で押し続けて連続削除 |
| ツールメニュー「確定を戻す」 | Mozc の UNDO（直前の確定のみ） |

> [!NOTE]
> 長押しカーソル移動は、反転時に待ち時間を置き、指を離す・キャンセル・キーボード非表示で停止します。変換中は文節単位、未変換中は読みの編集、確定後は入力先のカーソルを動かします。

## 候補領域とツールバー

候補があるときは候補一覧、ないときは同じ領域が Material アイコンの**ツールバー**になります。

| ツール | 役割 |
| --- | --- |
| 文体補正 | 未確定文字／カーソル直前の文を丁寧・簡潔・自然などへ端末内変換 |
| クリップボード | メモリ内履歴（最大 20 件）から貼り付け |
| 絵文字 | 最近・絵文字・顔文字・お気に入り |
| 片手モード | 全幅 → 左寄せ → 右寄せ → 全幅 を循環 |
| 設定 | 設定画面・AI 文章校正などへ |

5 つのボタンは候補領域の横幅いっぱいに等分されます。候補が出ると自動で候補一覧へ戻ります。

## 音声入力（任意モジュール）

本体と同じ署名・種類の音声入力モジュール APK を別途インストールし、キーボードのツールメニューから「音声入力」を選びます。モジュールのアプリアイコンからも用途やモデルを確認できます。初回は「日本語モデルを取得」を押してください（約48 MBの通信、展開後約99 MBの保存領域に加えて、一時ファイル用の空き容量が必要）。取得が終わったら「話す」を押し、初回はマイクを許可します。話し終えたら「話し終える」を押し、認識結果を確認して「入力する」を押します。モデルは同じ画面で削除できます。

認識は Vosk 日本語モデルを使用し、端末内で行います。約60秒で録音を終了します。途中で入力先や内容を変えた場合は結果を破棄します。入力中の未確定文字は音声入力の開始前に確定します。パスワードなどの機密欄や学習禁止欄では利用できません。実機での動作・精度・メモリ消費は未検証です。rc.58 では音声モジュールへ結果の返却先を渡す際の互換性を修正しています。

## 入力欄に応じた自動最適化

| 入力欄 | 動き |
| --- | --- |
| パスワード | Mozc シークレットモードを自動有効。学習せず、既存学習も変換に使わない |
| 数値 | 候補領域を非表示 |
| URL・メール | 英字 QWERTY と英語候補 |
| 複数行 | Enter は入力欄が明示していれば送信/検索などを優先、なければ改行 |
| 非リッチ（`TYPE_NULL`） | Backspace は DEL イベント、左右は DPAD キーとして送信 |

> [!IMPORTANT]
> パスワード欄を離れると通常モードへ戻ります。composition 同期により、Chrome のアドレスバーを「×」で消した後に消す前の読みが次の入力へ混ざることはありません。

## 入力の使い方ガイド

設定の「入力の使い方」から、フリック図・文節操作の体験・保存しない入力練習を備えた専用ガイドを開けます。初めての人はまずここで一通り試すのが最短です。

## 削除キーの二段階フリック（rc.39）

フリック配列の削除キーから指を滑らせ、吹き出しに出た操作を確認してから離します。

| 方向 | 少し動かす | さらに遠くへ |
| --- | --- | --- |
| 左 | カーソル左の単語 | カーソルから行頭まで |
| 上 | カーソル右の単語 | カーソルから行末まで |

操作は**指を離したときに1回だけ**実行します。移動中には削除せず、
最初に余分な1文字を消すこともありません。指を中央へ戻すと通常の1文字削除へ戻ります。
単にタップしたときは指を離して1文字削除し、中央で長押しすると従来どおり連続削除します。
連続削除が始まった後に指をずらすと停止し、そのまま単語・行の削除には切り替わりません。
単語・行削除は、指を離す前にタッチがキャンセルされれば実行しません。別の指が触れた場合も、
選択中の単語・行削除は取り消します。

行頭・行末は、画面上の折り返しではなく**改行で区切られた行**を指します。
改行は削除しません。単語削除もその行の中に限定し、カーソル側の空白がある場合は
空白と隣接する単語をまとめて対象にします。単語の区切りは端末の日本語用区切り処理を使います。

- 未確定入力がある場合は、その中だけを削除します。変換中はいったん読みに戻して削除し、残りは未確定のままです。
- 入力先で文字列を選択している場合は、その選択範囲だけを削除します。この場合は選択内の改行も対象です。
- 先頭・末尾で削除対象がない場合は何も削除しません。
- 入力先から文字列を読み取れない端末欄などでは単語・行削除を行いません。通常の削除は引き続き使えます。
- 自作配列で削除キーの方向に操作を割り当てている場合は、既存の割り当てを優先します。QWERTYの削除キーは変更しません。


## 入力応答の軽量化（rc.42）

キーの押下表示・フリックガイドに待ち時間付きのアニメーションはありません。従来はMozcの変換と描画が同じUIスレッドで走り、変換待ちがキー表示の遅れにもつながる構造でした。今回、次を削減しました。

- QWERTY・Godan・単純な数値パッドでは、フリック連打用の余分なMozcコマンドを送らない。
- フリックと数字／記号のトグル配列では連打・濁点・小文字に必要な処理を残し、表示しない中間候補の組み立てを省略。
- 1入力でNative候補と補助候補を続けて描き直す経路を1回へ。補助候補がない場合の重複順位付けも省略。AIが後から結果を返した場合の更新は維持。
- 2行候補とツールバーを再利用し、同じ文字・★アイコン・背景への不要な再設定を削減。
- Android 12以降で送信後の空欄を確認するときは小さな周辺テキストを先に取得。未対応の入力先・旧APIは抽出テキストへフォールバックし、短い取得量を要求。入力先が要求を無視する場合は全文が返ることがあります。

入力文字を間引いたり、候補行数や先読みを無効にする変更ではありません。Mozcの初期化・変換・文節操作・候補確定・設定反映は専用の直列ワーカーへ移しました。入力欄・Viewの操作はUIスレッドへ戻します。実機がないため、改善率・遅延・FPS・連打や入力先の互換性は未測定です。

### 非同期Mozcの順序と入力先の保護

同じ入力先の文字・削除・変換・確定は受付順に処理し、文字キーを間引きません。Nativeを複数同時に呼ぶ方式ではありません。待機中に配列が変わっても、各文字キーは押したときの配列・機密欄／補正／トグル設定を保持します。

入力先の終了・別欄への移動・外部での本文消去では、古い未処理イベントと結果を破棄し、新しい欄への混入を防ぎます。実行中のJNIを強制終了するのではなく、完了結果を受け取らず、その後の同一ワーカーでリセット・次の入力を進めます。同じ欄の再起動では順番を保ちます。

入力イベントと候補はメモリ内のみで処理します。任意の入力性能記録は、キー受付から待ち行列・Native処理・UI更新処理完了までの集計値です。実際のフレーム表示時刻やCPU時間ではありません。入力先アプリへのテキスト問い合わせや画面の計測・描画はUI側に残るため、あらゆる遅延がなくなる保証はありません。

長押しの自動リピート（削除・カーソル移動など）は、待機／実行中を合わせて1イベントまでに抑えます。指を離すと未実行分を取り消し、最初の通常押下は保持し、自動反復は既に受け付けて実行中の1回だけ完了します。Native処理が遅いときに削除や移動が大量に溜まって後から続くことを防ぎます。通常の物理打鍵や指の移動量に対応する操作は間引きません。


## 入力の途中で使い方を見る

候補のないときのツールバーまたはメニューボタンから「入力の使い方」を開けます。変換中に開くと文節の説明から始まります。ガイドには操作の図と実際の練習欄があります。
