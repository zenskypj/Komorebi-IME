# ほかのキーボードと比べる

このページは宣伝ではありません。各社が「こうしています」と**言っていること**、**実際に起きたこと**、そして**利用規約が許していること**を、専門用語を使わずに並べます。

> [!NOTE]
> 2026年11月時点の公開情報にもとづきます。各社の仕様は変わります。特定の製品を違法だと決めつけるものではありません。

## 先に結論

- **入力した文字を外に送っていないと「確かめられる」のは、ソースコードが公開されているアプリだけ**です。
- 大手は「送っていません」と言えます。でも、あなたがそれを確かめる方法はありません。
- Komorebi IME は入力を送りません。ソースコードも公開しているので、確かめられます。

## 何が送られるか

見方: **○ 送られる** / **△ 条件つき** / **× 送られない** / **— その機能がない** / **? 公開情報では分からない**

| | Komorebi IME | Gboard | Google 日本語入力 | Simeji |
| --- | --- | --- | --- | --- |
| 入力した文字 | × | △ 検索は送る | × | △ 設定をONにすると送る |
| 利用統計（使われ方の記録） | × | ○ | △ PC版は初期OFF | ○ |
| 音声入力の音声 | — | △ 使うと送る | — | △ 使うと送る |
| 広告のための利用 | × | △ Googleの広告 | — | ○ 規約に明記 |
| ソースコード | **公開** | 非公開 | 非公開 | 非公開 |

この表でいちばん右の列に注目してください。**3社とも、中身を確かめることはできません**。表の「×」も「○」も、会社の説明か、報道で分かったことです。

## 2013年に Simeji で起きたこと

| 日付 | 出来事 |
| --- | --- |
| 2013年12月26日 | セキュリティ会社が「Simeji が入力した内容を無断で外部に送っている」と指摘 |
| 同日 | 運営会社が「プログラムの不具合だった」と説明。**設定で記録をOFFにしていても、一部が送られていた** |
| 同日 | 不具合は**2013年3月の版から、約8か月間**続いていたと判明 |
| 2013年12月27日 | 修正版を公開。同時に「クラウド変換」を**初期設定でOFF**に変更 |

大事なのは最後の行です。直すときに、それまで初期設定でONだった「クラウド変換」をOFFに変えました。つまり問題の一部は不具合ではなく、**最初からONにしていた設定**でした。

そして、同じ会社のパソコン用ソフトでも、同じ時期に同じ問題が指摘されています。**1つの製品だけの事故ではありませんでした。**

## Gboard の場合

Google は自社のヘルプに、こう書いています。

| 送ると書いてある | 送らないと書いてある |
| --- | --- |
| 検索 | 検索**以外**に入力した内容（パスワードやチャットなど） |
| 利用統計 | 保存した単語 |
| 音声入力の音声 | |

ここは冷静に読む必要があります。**「検索」は、あなたが入力した文字そのもの**です。「入力は送らない」と言いながら、その横に「検索は送る」と書いてある。つまり「送らない」の範囲は、**会社が自分で決めている**ということです。

そして Gboard は、Android の最初から入っているキーボードです。特別に選ばなくても使われ、検索・音声・統計が同じ会社に集まります。

## 「ソースコードが非公開」って、何が困るのか

ソフトの中身が見られないと、**説明どおりに動いているかを外から確かめられません**。

2013年の件は、たまたまセキュリティ会社が通信を調べて見つけました。誰かが偶然調べなければ、8か月間そのままでした。**次に同じことが起きても、気づけないかもしれません。**

つまり、非公開のアプリを使うということは、**「信じる」以外に選べることがない**ということです。これは善し悪しではなく、仕組みの問題です。

## Simeji の規約が許していること

今の規約を読むと、次のように書かれています。

- 記録の対象に、**変換前の入力**（まだ変換していない文字）が含まれる。初期設定ではOFF。
- 確定した語とその読みを、**広告を出すために使う**ことがある。
- データは国内に置くが、**外国の会社に渡すことがある**。
- AI機能に入力した文章は **OpenAI に送る**。
- パスワードやカード番号は自動で見分けて取らない（見分けられなかったものは対象になり得る）。

「変換の精度を上げるためだけ」ではありません。**無料で広告で運営している以上、入力は広告の材料になります。** これは会社の善意の問題ではなく、商売の作り方の問題です。

## Komorebi IME の場合

| 項目 | 内容 |
| --- | --- |
| 入力した文字 | 送りません |
| 使われ方の記録 | 送りません（広告・解析の仕組みを入れていません） |
| 音声入力 | ありません |
| 通信するとき | モデルや追加辞書を、あなたがボタンを押したときだけ |
| 保存するデータ | 端末内で暗号化 |
| ソースコード | 公開（Apache-2.0） |

**弱点も書きます。**

| 弱点 | 内容 |
| --- | --- |
| まだテスト版 | 設定や保存形式が変わる可能性がある |
| AI の対応端末 | ニューラル変換とAI校正は、今は一部のCPUだけ |
| 実機での確認 | 一部の機能は確認が続いている |
| 機能の数 | 多言語・音声・翻訳は大手に及びません |

便利さの合計では負けます。勝っているのは**仕組み**です。

## どれを選ぶか

| あなたが大事にしたいこと | 選ぶもの |
| --- | --- |
| 入力した内容を外に出したくない | ソースコードが公開されたオフラインのキーボード |
| 確かめられないものを信じたくない | 同上 |
| 多言語・音声・翻訳をよく使う | 大手のキーボード（何が送られるか理解したうえで） |
| 設定を変えるのが面倒 | 最初から入っているキーボード（送られる範囲は公式ヘルプで確認） |

> [!TIP]
> どのキーボードでも、**パスワード欄で学習しない設定**と**「利用統計」の項目**は確認してください。Komorebi IME はパスワード欄で自動的に学習を止めます。

## 用語

| 言葉 | 意味 |
| --- | --- |
| ソースコードが公開 | プログラムの中身が誰でも読める。動作を第三者が確かめられる |
| ソースコードが非公開 | 中身を読めない。会社の説明を信じるしかない |
| 利用統計 | 「どの機能がよく使われたか」などの記録。設定で切れることが多い |
| クラウド変換 | 入力した文字を会社のサーバーに送って変換すること |
| 広告ID | 広告のために端末ごとに割り振られる番号 |
