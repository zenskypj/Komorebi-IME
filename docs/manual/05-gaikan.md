# 外観と配列

## キーボードの見た目

設定から次を変更できます。

| 項目 | 内容 |
| --- | --- |
| 入力方式 | かな/英字のフリック・QWERTY の組み合わせ |
| キーの高さ | 入力欄を見ながら調整し、保存・取消・標準へ戻す |
| バイブ | テーマに関係なく「入力方式」からオン・オフ |
| ピュアブラック | 有効にすると黒基調 |
| 背景画像 | 自分の画像、または生成アートのプリセット |
| 背景の濃さ | 背景の上に重ねる暗さ |
| 片手モード | 全幅・左寄せ・右寄せ |

背景画像のプリセットは 4 種類あります。

| プリセット | 印象 |
| --- | --- |
| 森のともだち | 緑と木漏れ日 |
| 水晶の藤 | 青紫の光 |
| サイバー墨 | 墨色にネオン |
| 月夜のこもれび | 夜の森 |

> [!NOTE]
> 背景画像と濃さだけを変えた場合は、表示中の入力ビューを作り直さず、背景パネルをその場で再描画します。設定画面から戻った直後もナビゲーション領域との位置関係を維持します。

## 片手モード

候補がないときのツールバーの 1 ボタンをタップするたびに、**全幅 → 左寄せ → 右寄せ → 全幅** と循環します。端末枠内のキーボード位置を模したインジケーターで現在のモードを表示します。

## 配列・テーマスタジオ

設定の「プリセット選択・自作・共有」から開きます。配列とテーマは JSON です。

| できること | 内容 |
| --- | --- |
| 使用 | 同梱プリセットまたは作成済みデータを選ぶ |
| 視覚エディタ | キーを選んで行内・行間を移動、キー幅・表面ラベル・長押し記号を GUI 編集 |
| 複製 | JSON の `id` を変更して既存プリセットを複製 |
| JSON 編集 | 直接編集し、形式と値を検証して保存 |
| 入出力 | Android のファイル選択画面から JSON を取り込み・書き出し |
| 復元 | ユーザー版を削除し、同名の同梱プリセットへ戻す |

| 制約 | 内容 |
| --- | --- |
| ID | 1〜64 文字の英数字・ハイフン・アンダースコア |
| 優先 | 同じ ID のユーザー版が同梱版より優先 |
| 上限 | 1 ファイル 1 MB。空の配列・過大な行/キー数・範囲外のサイズは保存されない |
| Material You | 端末配色から動的生成されるため、直接編集・書き出しの対象外 |

> [!NOTE]
> 視覚エディタはキー移動・幅・ラベル・長押し記号に対応します。フリック方向や特殊アクションなど全項目の編集には JSON エディタを使います。作成数にアプリ側の固定上限はありません。

## 記号とフリック

| 項目 | 内容 |
| --- | --- |
| 記号面 | 2 ページ。`1/2`・`2/2` で切り替え |
| 1 ページ目 | 一般的な記号 |
| 2 ページ目 | 括弧、引用符、比較・演算、矢印、プログラミング記号 |
| 連打 | 「フリックのみ」／「フリック＋ケータイ打ち」を選択 |
| 長押し記号 | 配列 JSON の各キーへ `longPress` を追加すれば任意の直接入力記号を割り当て |

## アプリ別入力プロファイル

設定の「アプリ別入力プロファイル」で、アプリごとに次を自動適用できます。

| 項目 | 内容 |
| --- | --- |
| 入力方式 | アプリごとのキーボード |
| 片手モード | 全幅・左・右 |
| キーの高さ | そのアプリ用の高さ |
| Mozc シークレットモード | そのアプリで学習しない |
| AI の許可 | AI 変換の可否 |
| 入力補正の許可 | 誤入力補正の可否 |

- インストール済みアプリを列挙する権限は追加していません。Android から IME へ通知された、**実際に入力したアプリのパッケージ名だけ**を端末内に記録し、設定候補として表示します。
- パッケージ名を手入力して先に設定を作ることもできます。
- パスワード欄のシークレット設定は常に優先され、プロファイルで無効化できません。

## パフォーマンス診断

設定から有効にすると、キー処理と AI 推論の**回数・合計時間・最大時間**だけを端末内に保存します。入力本文・周辺文脈・アプリ名は記録しません。記録は設定から消去できます。
