# 外観と配列

## 背景と着せ替え

以下は rc.51-dev 以降の操作です。

**設定 → 外観 → キーボードの背景**から、画像プリセット13種、写真1〜4枚、または動画1本を選べます。複数の写真は5〜120秒ごとに切り替わります。濃さ、明るさ、ぼかし、横・縦位置とフィルターはプレビューで確認できます。動画は24 MiB・120秒・最大辺1920px以内で、再生開始と終了を指定できます。無音でループし、キーボードを閉じると再生を止めます。動画のぼかしはAndroid 12以降です。外観で選んだ背景はテーマの背景に優先します。

**設定 → 配列とテーマ → テーマ**から完成テーマを選べます。苔の森、湖の宵、梅の和紙、夜の雨、島の浅瀬、夕暮れの砂丘、雪明かり、冬のオーロラ、墨と和紙の9種を追加しました。背景9点とキー用9点の[生成素材](../research/keyboard-theme-art.md)を同梱しています。

「テーマを編集」ではフリックとQWERTYのプレビューを切り替えられます。

| 項目 | 調整できる内容 |
| --- | --- |
| 枠と画像 | 塗りつぶし、個別の枠、仕切り線、枠なし、破線、グラデーション。線幅・角丸・キーの高さと間隔・透明度。背景イラスト、文字キーと操作キーの画像、雪と光の演出 |
| 配色 | 背景、キー、押下、枠、文字、フリックガイド、候補、ツールバー。色相・彩度・明るさ・不透明度、または色コードで指定 |
| 文字と反応 | 書体、文字サイズ、太字、影、長押しヒント、ガイドの表示方式、タップ演出、押したときの強調。端末標準音と合成音3種 |
| 入力エフェクト | 32文字までの語と画像を最大8件登録。語を含む変換結果を確定すると、画像をキーボードに短く表示 |

書体の表示はAndroidにあるフォントに依存します。文字サイズを大きくしすぎると一部の表示が小さく調整されることがあります。機密欄・シークレット入力では動画と入力エフェクトを再生しません。

## キーを1個ずつ変える

**設定 → 配列とテーマ → 配列エディタ**で配列とキーを選び、「このキーの外観を編集」を開きます。そのキーだけの枠、背景色、文字色・太さ・サイズ、画像、ラベルと長押しヒントの表示を変更できます。端末の写真をキー画像にしてラベルを消すこともできます。外観を変えても、押したときの入力は保持されます。同じ画面からキーの移動・幅・タップ動作・フリック文字・長押し記号も編集できます。

テーマと配列のJSONは取り込み・書き出しができます。IDは英数字、ハイフン、アンダースコアで1〜64文字、取り込めるJSONは1 MiBまでです。同じIDのユーザー版が同梱版に優先し、ユーザー版を削除すると同梱版に戻ります。Material Youから作る場合は別のIDに保存します。端末から選んだ画像・動画はJSONに含まれず、端末間で移す場合は[暗号化バックアップ](07-iten.md)を使います。キー・入力エフェクト用の端末画像は共通で最大80枚保存できます。

## 高さ・片手モード・振動

高さと片手モードは「外観」またはキーボード上のツールから変更できます。片手モードのボタンを押すたびに**全幅 → 左寄せ → 右寄せ → 全幅**と切り替わります。振動は「入力方式」、ピュアブラックは「外観」で切り替えます。

## 記号とフリック

| 項目 | 内容 |
| --- | --- |
| 記号面 | 2 ページ。`1/2`・`2/2` で切り替え |
| 1 ページ目 | 一般的な記号 |
| 2 ページ目 | 括弧、引用符、比較・演算、矢印、プログラミング記号 |
| 連打 | 「フリックのみ」／「フリック＋ケータイ打ち」を選択 |
| 長押し記号 | 配列 JSON の各キーへ `longPress` を追加すれば任意の直接入力記号を割り当て |

## アプリ別入力プロファイル

設定の「アプリ別入力プロファイル」で、アプリごとに次を自動適用できます。

| 項目 | 内容 |
| --- | --- |
| 入力方式 | アプリごとのキーボード |
| 片手モード | 全幅・左・右 |
| キーの高さ | そのアプリ用の高さ |
| Mozc シークレットモード | そのアプリで学習しない |
| AI の許可 | AI 変換の可否 |
| 入力補正の許可 | 誤入力補正の可否 |

- インストール済みアプリを列挙する権限は追加していません。Android から IME へ通知された、**実際に入力したアプリのパッケージ名だけ**を端末内に記録し、設定候補として表示します。
- パッケージ名を手入力して先に設定を作ることもできます。
- パスワード欄のシークレット設定は常に優先され、プロファイルで無効化できません。

## パフォーマンス診断

設定から有効にすると、キー処理と AI 推論の**回数・合計時間・最大時間**だけを端末内に保存します。入力本文・周辺文脈・アプリ名は記録しません。記録は設定から消去できます。
