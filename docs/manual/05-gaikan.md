# 外観と配列

## 背景と着せ替え

**設定 → きせかえ**を開きます。画面上部のアイコンで背景・テーマ・ボタンなどを切り替えます。「開く」を押すか試し入力欄に触れると、現在選択中のIMEが開きます。Komorebi IMEを選択しているとき、編集中のテーマや背景が試し入力欄でのみ一時的に反映され、実際の変換も試せます。「閉じる」でキーボードを隠せます。キーボード表示中も項目と開閉ボタンはキーボードの上に表示されます。配色を切り替えると、キーボード上段のツール列と左端メニューもプレビューに追従します。試し入力欄は学習禁止です。

「テーマ」でイラスト付きや色のテーマを選ぶと、まずプレビューに反映します。「配列」ではかな・英字のフリック／QWERTYや記号のプリセットを試せます。「完了」で使用するテーマを切り替えます。キーや配色を調整したら「完了」で別テーマとして保存して適用できます。「テーマ」に戻ると名前を付けられます。「このテーマの変更を元に戻す」で未保存の調整を戻せます。背景の写真や動画は選択時に反映されるため、背景で解除します。「キーを見やすくする」でキー面を濃くし文字に影を付けられます。完成テーマには苔の森、湖の宵、梅の和紙などがあり、背景9点とキー用9点の[生成素材](../research/keyboard-theme-art.md)を同梱しています。

「背景」では、画像プリセット13種、写真1〜4枚、動画1本を選べます。この項目で選んだ画像・動画は、選択と同時に使用する背景に反映されます。画像を選ぶと、代表色から文字・キー・候補・ツールバーなどをまとめて調整します。自分の画像・動画では画像が見えるよう、キー面は薄く、上段と候補の背景は透明にします。フリックガイドとツール一覧には背景を付けます。新たに読み込む写真・動画の背景の濃さは100%から始まり、変更できます。自動調整の結果はプレビューに反映され、「完了」で適用します。以前に保存したテーマには、画像を選び直すか「配色」→「背景画像に色を合わせる」で反映できます。その後も「配色」で画像に合わせ直したり、文字とアイコンの色の一括変更や個別調整ができます。動画は先頭フレーム、複数写真は最初の写真を参照するため、画像によっては手動調整が必要です。直近の自分の写真・動画は一覧に選択マーク付きで表示され、プリセットに切り替えた後も選び直せます。「自分の画像・動画を一覧から削除」でアプリ内コピーを削除できます（元の写真は削除しません）。写真の間隔は5〜120秒、濃さ・明るさ・ぼかし・縦横位置・フィルターはプレビューを見ながら調整できます。動画は24 MiB・120秒・最大辺1920px以内、無音で指定区間をループします。動画のぼかしはAndroid 12以降です。選んだ写真・動画はテーマの背景イラストに優先し、「選んだ背景を解除」で戻せます。

| 項目 | 調整できる内容 |
| --- | --- |
| キー | 塗りつぶし、個別の枠、仕切り線、枠なし、破線、グラデーション。線幅・角丸・キーの高さと間隔・透明度。四角、角丸、大きな丸みのプリセットと、文字キー・操作キーの画像 |
| 背景 | テーマのイラスト、写真・動画、雪・光の演出 |
| 配色 | 背景画像からの一括調整、文字とアイコンの色の一括指定。背景、キー、押下、枠、文字、フリックガイド、候補、ツールバーの個別調整。色相・彩度・明るさ・不透明度、または色コードで指定 |
| 文字と反応 | 書体、文字サイズ、太字、影、長押しヒント、ガイドの表示方式、タップ演出、押したときの強調。端末標準音と合成音3種 |
| 入力エフェクト | 32文字までの語と画像を最大8件登録。語を含む変換結果を確定すると、画像をキーボードに短く表示 |

書体の表示はAndroidにあるフォントに依存します。文字サイズを大きくしすぎると一部の表示が小さく調整されることがあります。機密欄・シークレット入力では動画と入力エフェクトを再生しません。

「小・濁点」キーは文字キーとして扱い、文字キーの色や画像が適用されます。

## キーを1個ずつ変える

**設定 → きせかえ → キー → キーを一つずつ編集**から配列エディタを開いてキーを選び、「このキーの外観を編集」を開きます。そのキーだけの枠、背景色、文字色・太さ・サイズ、画像、ラベルと長押しヒントの表示を変更できます。端末の写真をキー画像にしてラベルを消すこともできます。外観を変えても、押したときの入力は保持されます。同じ画面からキーの移動・幅・タップ動作・フリック文字・長押し記号も編集できます。

「テーマ」「配列」それぞれの「詳細・JSON入出力」で、JSONを取り込み・書き出しできます。IDは英数字、ハイフン、アンダースコアで1〜64文字、取り込めるJSONは1 MiBまでです。同じIDのユーザー版が同梱版に優先し、ユーザー版を削除すると同梱版に戻ります。Material Youから作る場合は別のIDに保存します。端末から選んだ画像・動画はJSONに含まれず、端末間で移す場合は[暗号化バックアップ](07-iten.md)を使います。キー・入力エフェクト用の端末画像は共通で最大80枚保存できます。

## 高さ・片手モード・振動

高さと片手モードは「表示とサイズ」またはキーボード上のツールから変更できます。片手モードのボタンを押すたびに**全幅 → 左寄せ → 右寄せ → 全幅**と切り替わります。振動は「入力方式」、ピュアブラックは「表示とサイズ」で切り替えます。

## 記号とフリック

| 項目 | 内容 |
| --- | --- |
| 記号面 | 2 ページ。`1/2`・`2/2` で切り替え |
| 1 ページ目 | 一般的な記号 |
| 2 ページ目 | 括弧、引用符、比較・演算、矢印、プログラミング記号 |
| 連打 | 「フリックのみ」／「フリック＋ケータイ打ち」を選択 |
| 長押し記号 | 配列 JSON の各キーへ `longPress` を追加すれば任意の直接入力記号を割り当て |

## アプリ別入力プロファイル

設定の「アプリ別入力プロファイル」で、アプリごとに次を自動適用できます。

| 項目 | 内容 |
| --- | --- |
| 入力方式 | アプリごとのキーボード |
| 片手モード | 全幅・左・右 |
| キーの高さ | そのアプリ用の高さ |
| Mozc シークレットモード | そのアプリで学習しない |
| AI の許可 | AI 変換の可否 |
| 入力補正の許可 | 誤入力補正の可否 |

- インストール済みアプリを列挙する権限は追加していません。Android から IME へ通知された、**実際に入力したアプリのパッケージ名だけ**を端末内に記録し、設定候補として表示します。
- パッケージ名を手入力して先に設定を作ることもできます。
- パスワード欄のシークレット設定は常に優先され、プロファイルで無効化できません。

## パフォーマンス診断

設定から有効にすると、キー処理と AI 推論の**回数・合計時間・最大時間**だけを端末内に保存します。入力本文・周辺文脈・アプリ名は記録しません。記録は設定から消去できます。

「テーマ」で写真・動画をプリセットに保存できます。「テーマ一式を読み込む」で内容を確認して新規追加し、設定だけ、または保存済み背景を含めて書き出せます。自動切り替えはダークモードや時刻で設定でき、アプリ別プロファイルの指定が優先されます。「配色」には黒・白のくっきり配色と、動く演出を減らす設定があります。
