# データの移行

機種変更や再インストールのときに、設定・学習・辞書を移す方法は 3 つあります。

| 方法 | 向いている場面 | 端末 |
| --- | --- | --- |
| ファイルバックアップ | 保存先を選んで残したい | 1 台 |
| NFC 移行 | 手元の 2 台間で一気に移したい | 2 台 |
| Meets Beam | テキスト・URL・アプリを送る | 2 台 |

> [!IMPORTANT]
> zenzai-plus のモデルと TTT 学習重みは、どの方法でも移行しません（サイズが大きく、既存バックアップのメモリ制限も超えるため）。移行後は必要に応じて再取得・再学習してください。

## ファイルバックアップ

明示操作で、辞書・Mozc 学習・設定などを**利用者のパスフレーズ**で暗号化して書き出します。

| 含まれるもの | 含まれないもの |
| --- | --- |
| Mozc の学習履歴・ユーザー辞書 | zenzai-plus のモデル・TTT 重み |
| 設定・独自配列・テーマ・背景 | 校正モデル |
| アプリ別設定・意味辞書・最優先候補 | |

1. 設定からバックアップを作成し、パスフレーズを決めます。
2. 書き出したファイルを新しい端末へ移します。
3. 復元を実行します。**復元は次回のプロセス起動時に反映**されます。

> [!WARNING]
> パスフレーズを忘れると復元できません。復元すると、受信側の同じ項目は上書きされます。操作前に受信側のバックアップを取ってください。

## NFC による移行

両端末で「NFC で設定・学習を移行」を開き、片方で送信、もう片方で受信を選びます。NFC を有効にし、受信完了まで端末を近づけ続けます。送信側には HCE（カードエミュレーション）対応が必要です。

| 項目 | 内容 |
| --- | --- |
| 方式 | 一時的な ECDH 鍵交換 + AES-GCM |
| 対象 | 設定・背景・Mozc の学習・ユーザー辞書など |
| 対象外 | zenzai-plus のモデル・TTT 重み |
| 上限 | 32 MiB |
| 通信 | 端末間のみ。クラウドに送らない |

送信側は画面を開いている間だけ HCE の対象 AID を優先サービスへ設定し、検出・完了を画面に表示します。受信側は受信の検証が成功したときだけ送信側へ完了を返します。

> [!WARNING]
> 相手端末の本人確認は行いません。**信頼できる自分の端末同士**で操作してください。データ量によっては時間がかかります。受信成功後はアプリを終了して開き直すと反映されます。

## Meets Beam（実験的）

テキスト・URL・アプリを NFC で送ります。初期状態では無効です。両端末で有効にし、送信側・受信側を選びます。

| 送るもの | 方法 |
| --- | --- |
| テキスト | Android の選択メニュー「Meets Beam で送る」または共有メニュー（最大 32 KiB） |
| URL | 任意のユーザー補助を有効にすると、送信操作時に対応ブラウザのアドレス欄から取得 |
| アプリ | 編集欄のアプリを送る。受信画面から起動、未インストールなら Play ストアを開く |

受信したテキストはクリップボードにコピーします。内容は暗号化されますが、相手端末の本人確認は行いません。

> [!NOTE]
> ユーザー補助は初期状態では無効です。許可した場合も送信操作時だけ対応ブラウザの URL 欄を参照し、それ以外の画面内容は保持しません。取得できない場合はブラウザの共有メニューを使ってください。

## 困ったときの優先順

1. まず**両端末でバックアップ**を取る（NFC・Beam の前に）。
2. NFC が反応しない → 端末を離さず近づけ直す。「受信を再試行」を使う。
3. 反映されない → アプリを終了して開き直す（NFC 移行は再起動後に反映）。
