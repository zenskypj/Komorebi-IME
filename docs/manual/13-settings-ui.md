# 設定画面

設定を開くと、「キーボード」「変換と辞書」「データと共有」「情報」が上から順に並びます。各項目を押すと編集画面が開きます。

- **キーボード**：入力方式、きせかえ（テーマ・背景・キー・配列）、表示とサイズ、定型文、入力の使い方。背景やキーの変更手順は[外観と配列](05-gaikan.md)を参照してください。Komorebi IME が未選択の場合は、一覧の先頭に初期設定の案内が出ます。
- **変換と辞書**：変換エンジン、AI文章校正、変換学習、ユーザー辞書、意味辞書。
- **データと共有**：バックアップと移行、Meets Beam、アプリ別設定。「バックアップと移行」を開くと、ファイルへの書き出し・読み込みや NFC 移行を行えます。
- **情報**：オープンソースライセンス、バージョン情報など。

右上の虫眼鏡から、項目名・説明・関連語でカテゴリをまたいで検索できます。「Mozc」「高さ」「バックアップ」などの語で探せます。検索結果から設定を開いて戻ると、検索語は残ります。検索を閉じると元の一覧に戻ります。

このページは rc.52-dev の設定画面を説明しています。実機での表示・操作は未確認です。
