# トラブルシューティング

## インストール・起動

| 症状 | 原因の候補 | 対処 |
| --- | --- | --- |
| APK がインストールできない | 提供元不明アプリが許可されていない | 端末設定で許可する。署名が異なる既存版があれば先に削除 |
| フォーク元と二重に入る | application ID が異なる（`me.zssu.ime`） | 仕様です。共存します |
| 設定が引き継がれない | フォーク元・旧 `dev.oss.ime` からは自動移行しない | [データの移行](07-iten.md) でバックアップ/NFC を使う |
| キーボード一覧に出ない | 有効化・選択が未完了 | 設定の「キーボードを有効化」「キーボードを選択」を順に実行 |

## 入力・変換

| 症状 | 原因の候補 | 対処 |
| --- | --- | --- |
| 変換できない | ネイティブ成果物が APK に無い（自分でビルドした場合） | `libmozc.so` と `mozc.data` を確認して再ビルド |
| 意図しない候補が先頭に出る | AI 変換が先頭に出ている | 該当語をユーザー辞書へ登録するか ★ を付ける（個別指定は AI より優先） |
| 誤変換が直らない | 誤学習 | 候補を長押し→「学習削除」、または設定で学習リセット |
| 未確定の読みが消えない | 入力欄側の変更 | 一度確定するか Backspace。composition 同期で次入力へは混ざりません |
| 補正が邪魔 | 誤入力補正が強すぎる | アプリ別プロファイルで補正を無効化 |
| パスワード欄で変換しない | シークレットモード | 仕様です。学習も行いません |

## AI 機能

| 症状 | 原因の候補 | 対処 |
| --- | --- | --- |
| AI 変換が動かない | モデル未取得・`arm64-v8a` 以外 | 「変換エンジン・辞書」でモデル取得。非対応 CPU では Mozc へフォールバック |
| AI 文章校正の適用ができない | 入力欄が変わった／元の文章が変化した | 対象を確認できないときはコピーを使う |
| 校正結果がおかしい | 小さいモデルが指示を守らない | 差分を確認。Qwen3 1.7B を試す。意味の変更は適用しない |
| 結果が使えない | 生成後に元の文章や指示を変えた | その結果は古い扱いです。もう一度生成する |
| 発熱・電池 | AI 推論 | 使わないときは AI を OFF にする |

## 辞書

| 症状 | 原因の候補 | 対処 |
| --- | --- | --- |
| 追加システム辞書を取得できない | 互換性・空き容量 | アプリ更新で互換性が変わると取得不可。空き容量を確保 |
| 「まだ提供されていません」と出る | 選択した組み合わせの統合データセットが未提供 | 対応する統合データセットを取得する |
| 切り替わらない | 入力中・未確定がある | 入力欄を離れ、未確定をなくすと切り替えます |
| TSV 取込が失敗する | 形式・サイズ | TSV の形式とサイズを確認。取り込みは現在の辞書を置き換えます |
| 意味が出ない | 完全一致していない | `term` と候補文字列を完全一致させる |

## データ移行

| 症状 | 原因の候補 | 対処 |
| --- | --- | --- |
| NFC が反応しない | 端末が離れた・HCE 非対応 | 近づけたまま保持。送信側に HCE が必要 |
| Wi-Fi Direct に繋がらない | Wi-Fi オフ・権限未許可・相手のグループ作成失敗 | Wi-Fi をオンにし、近接端末（Android 13+）または位置情報（Android 12 以下）を許可。両端末で Beam を開き直す |
| Beam の転送が途中で止まる | 画面を離れた・サイズ/SHA-256 不一致 | 画面を開いたまま再試行。サイズを取得できる共有元を使う |
| 辞書を取り込めない | TSV でない・5 MB 超 | TSV の形式とサイズを確認 |
| 反映されない | 再起動前 | アプリを終了して開き直す |
| 復元できない | パスフレーズ相違 | パスフレーズを忘れると復元できません |

## ログの取り方

不具合報告には次を添えてください。

1. 端末名と Android バージョン
2. 入力した文字と期待した結果・実際の結果
3. 再現手順

> [!WARNING]
> 入力内容を含むログは公開前に必ず確認してください。個人情報や機密をそのまま貼らないでください。

## それでも直らないとき

- 設定 →「入力の使い方」で基本操作を確認
- アプリを再起動（IME プロセスは他アプリの切替で再生成されます）
- [既知の制約](09-spec.md#既知の制約) を確認
- 改善しない場合は、上記情報を添えてサポート（[support@zslink.xyz](mailto:support@zslink.xyz)）へ連絡

## 更新通知が届かないとき

設定の「Komorebi IME について」で「更新を自動確認」がオンか確認してください。「今すぐ確認」では通知の許可がなくても結果を表示できます。Android 13 以降は更新通知を許可し、Android のアプリ通知設定も確認してください。自動確認の時刻は端末の省電力制御やネットワーク接続により前後します。更新を自動ダウンロード・自動インストールする機能ではありません。

## 音声入力画面がすぐ閉じるとき

本体を rc.58 以降へ更新してください。音声モジュールと本体は同じ署名の組み合わせが必要です。修正後の実機動作は未検証です。

## マイクの許可が出ない・音声を聞き取れないとき

本体 rc.62 と音声モジュール 0.3.0 の両方へ更新し、ツールの「音声入力」を押してください。最初のマイク許可後に日本語モデルが未取得なら、表示される準備画面で取得して入力欄からもう一度押します。許可を繰り返し拒否した場合は、端末のアプリ設定で「Komorebi 音声入力」のマイクを許可してください。別のアプリがマイクを使用している場合も、使用を終えて再試行してください。実端末での動作は未検証です。

## チャットアプリの候補を選んだ後、次の入力に古い文字が混ざる

rc.66 以降では、入力欄が空になった場合に加え、入力先が候補で文字を置き換えた場合も、次の操作の前に IME 側の古い変換状態を破棄します。入力先がカーソル付近の文字や未確定範囲を返さない場合は判定できないことがあります。
