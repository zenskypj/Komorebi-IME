# 変換と候補

## 変換の基本

未変換中に **スペース** を押すと、Mozc が読みを一般的な日本語 IME と同じように文節へ自動分割して変換します。

| 状態 | 表示 |
| --- | --- |
| 未変換 | 読みがそのまま。候補領域は予測候補またはツールバー |
| 変換中 | IME が扱う全範囲を薄いオレンジ、選択文節を濃いオレンジ |

| 操作 | 動き |
| --- | --- |
| スペース | 文節変換・候補の切り替え |
| 左右キー | 対象文節を移動 |
| スペース左右フリック | 選択文節の境界を縮小・拡大 |
| Enter | 変換1回目の直後は文全体を確定。変換を重ねた後・文節移動後・候補選択後は選択中の文節までを確定 |
| 候補をタップ | その候補で確定 |

## 候補の並び

候補は出自と読みの進み具合で順位を調整します。固有名詞・登録語の前方一致予測は読みの途中から候補へ入り、近づくほど加点します。読みが異なる語への補正には別の抑制を保ちます。

| 区分 | 意味 |
| --- | --- |
| 入力どおり | 読みに対応する候補 |
| 補正 | フリックずれ・促音脱落・重複・転置を直した候補（「補正」表示） |
| 予測 | 読みの途中から出す候補。固有名詞・登録語は前方一致と入力の進み具合で段階的に上がる |
| かな表記 | 入力全文の ひらがな・カタカナ・半角カタカナ を常に候補内へ残す |
| ★ 最優先 | 明示登録した候補。読みが一致したとき先頭へ固定 |

> [!NOTE]
> 「補正」はルールベースです。4 文字以上の読みは、1 文字の挿入・削除・置換・隣接転置（8 文字以上は 2 編集）まで類似一致として復元します。

## 誤入力補正

次のような入力を自動で補正します。

| 種類 | 例 |
| --- | --- |
| フリックずれ | 隣接キーとの方向類似度で補正 |
| 促音・撥音の脱落 | 「がっこう」の「っ」抜けなど |
| 重複入力 | 同じキーの連打 |
| 隣接文字の転置 | 2 文字の入れ替わり |

補正の可否はアプリ別プロファイルから切り替えられます。

## 候補の長押しメニュー

候補を長押しすると、次の操作ができます。

| 操作 | 内容 |
| --- | --- |
| 意味を表示 | JSON 意味辞書に登録した語の意味・タグ・出典 |
| 最優先に登録（★） | 同じ読みでその候補を先頭へ固定。4 文字以上は類似一致も対象 |
| 最優先を解除 | 登録済みの ★ を外す |
| 学習削除 | 学習に由来し削除可能な候補だけ表示 |

## 学習

| 対象 | 保存先 | 暗号化 |
| --- | --- | --- |
| Mozc の変換学習履歴 | `files/mozc/.history.db` | Keystore 由来の鍵 |
| ユーザー辞書 | `files/user_dictionary.enc` / `files/mozc/user_dictionary.db` | AES-GCM + Keystore |
| 最優先候補（★） | `files/priority_candidates.enc` | AES-GCM + Keystore |
| zenzai-plus の TTT 学習 | チェックポイント | AES-GCM + Keystore |

学習のオン・オフ、リセット、候補の個別削除は設定と長押しメニューから行えます。パスワード欄、シークレットモード、学習禁止フラグのある入力欄、クリップボードから貼った本文は学習しません。

> [!TIP]
> 誤学習が気になったら、まず該当候補を長押しして「学習削除」。まとめて直したい場合は設定から学習履歴をリセットします。

## AI との優先関係

zenzai-plus / Karukan の候補は通常は先頭に表示されますが、**利用者が個別に指定した語**（ユーザー辞書・追加システム辞書への登録、★ の優先指定）がある読みでは、その語を先頭に保ち、AI に押しのけられません。

| 読みの状態 | 先頭に来る候補 |
| --- | --- |
| 個別指定あり | 利用者が指定した語（AI 候補はその次） |
| 個別指定なし | AI 候補（zenzai-plus / Karukan）、なければ Mozc |

> [!NOTE]
> 対象は「利用者が個別に指定した内容」に限ります。Mozc 本来の語彙・予測・訂正は従来どおり順位付けされ、AI を無効にしている場合も、Mozc順位に固有名詞・登録語の先読み調整を加えます。

## rc.37 の補正・優先指定

NEologdの名詞表記ゆれから得た66,378組の読み・正規表記を、Mozcが返した補正候補の
順位調整に利用します。同音語を自動で一つに決めたり、活用語を原形へ戻したりはしません。
カタカナ語→英語は読みが完全一致するときだけ補助候補に出し、誤入力補正には使いません。
旧版で大量ユーザー辞書に登録されていた英語コピーは、アプリ更新後に除去します。
個人辞書や最優先指定そのものは削除しません。

★の完全一致指定は、Mozcの候補プール外でも補い、zenzai-plusとKarukanの両方より
優先します。AIが後から結果を返しても、その時点の★指定を読み直して順番を保ちます。
通常の個別辞書登録より★を先にします。類似読みの★でAIを強制上書きはしません。

## 固有名詞・登録語の先読み（rc.40）

完全一致を待たず、読みが前方一致する語を候補へ追加します。たとえば「さい」「さいた」「さいたま」と入力を進める間にも、同梱の「さいたま市」が対象になります。

- 対象は同梱固有名詞・AI用語、個人ユーザー辞書、★登録語です。無効にした同梱辞書は補助予測に使いません。
- 補助候補は原則2文字以上から。読みの入力率が低いうちは控えめに残し、近づくと上位へ加点します。Mozcから来た順位・学習情報も使います。
- かな表記3種類だけで枠が埋まらないようにし、有効な前方一致候補を通常候補の先頭側3件内へ残します。★などの明示優先がある場合はその後です。表示行数の設定は維持します。
- 入力率は正解確率ではありません。文脈や競合候補も影響するため、必ず一定順序で1位になるとの保証はありません。
- 候補を選ぶまでは、先読みした本文へ勝手に置換しません。AIの通常優先は維持し、入力途中の語を完全一致登録と誤認してAIを強制的に押しのけません。完全一致の★指定は引き続きAIより優先します。
- 前方一致は誤補正とは別です。カタカナ語→英語辞書は完全一致のみを維持します。英字表記の固有名詞や自分で登録した語は、固有名詞・登録語として対象になります。

先読み候補を選んで学習するときは、語の完全な読みを使います。短い入力をその語の省略読みとして自動登録しません。先読み候補の★登録も、その語の完全な読みに対して行います。

## 英語候補の順位（rc.41）

かな読みからの英字表記は、読みが完全一致しても漢字・カタカナ・ひらがなの候補より後ろへ表示します。内蔵辞書・ダウンロードした追加システム辞書・旧ユーザー辞書由来の英語候補に同じ表示規則を使います。予測と変換中の両方に適用し、候補そのものは削除しません。

辞書由来というだけで英語候補を完全一致の最優先登録と扱い、AIや日本語候補の前へ戻す処理も抑止します。明示的な★最優先指定は維持します。個人辞書と確認できた登録のライブ優先・固有名詞の入力途中の予測・英字を直接入力しているときの順位は維持します。変換候補のIDは変更せず、最初の変換では表示先頭のNative候補を選びます。

現在のAPIには辞書ファイル単位の出典がないため、かなの読みと英字のみの表記（全角も正規化）から判別します。混在表記や辞書ごとの品詞・コストの全面調整は対象外です。実機での順位・操作感は未確認です。
