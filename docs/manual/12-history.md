# 開発の歴史とタイムライン

GitHub のリリース・タグ・[リリースノート](/docs/releases) を突き合わせた、Komorebi IME の完全な履歴です。**欠番も隠さず書いています**。

> [!NOTE]
> 日付は GitHub の公開日時（JST 前後）です。2026年7月の短期間に多数の版が出ているのは、フォーク直後に集中的に改善を回したためです。

## タイムライン

### v0.1.0-komorebi.5 — 2026-07-27

- 一般向け初回リリース。ここから Komorebi IME の公開が始まる。

### v0.1.0-komorebi.6 — 2026-07-27

- フォーク元からの移植: 完全一致候補を予測より上位へ（exactReadingFirst）、単一行フィールドの Enter 修正、候補チップの View 再利用、JNI 出力の軽量化（78 KB → 250 バイト）、フリックガイドの表示切替。
- この版までに、誤入力補正・固有名詞/AI 辞書・意味辞書・片手モード・アプリ別プロファイル・視覚的配列エディタ・絵文字・背景プリセット・ピュアブラック・キーボード高さ・テーマ・ブランドと法務文書を搭載。

### v0.1.0-komorebi.7 — 2026-07-27

- ツールバー非表示バグ、exactReadingFirst の順序破壊、2ページ目のフォーカス消失を修正。
- 配列エディタを大幅強化（アクション種別・キースタイル・複製/追加/削除）、テーマエディタとプリセット8種、JSON エディタの折りたたみ。

### v0.1.0-komorebi.8 — 2026-07-27

- 設定画面を全面刷新。ヒーローヘッダー、TopAppBar、Material Icons、FilterChip、統一した角丸。

### v0.1.0-komorebi.9 — 2026-07-27

- 設定画面をカラフルなダッシュボード形式（9カテゴリ）へ。配列・テーマスタジオも同時に刷新。

### v0.1.0-komorebi.10 — 2026-07-27

- 設定画面を1行1項目のリスト型へ再設計し、専用サブページへ遷移する深掘り型に。QWERTY の下段左端を「かな」に統一。

### v0.1.0-komorebi.11 — 2026-07-27

- 候補長押しから `★` 最優先候補を登録・解除。読みと表記は Keystore で暗号化保存。
- 補正候補に「補正」ラベルを付け、入力どおり → 補正 → 予測の順を明示。上位32候補に絞って読み・表記・出自を正しく受け渡す JNI 修正。

### v0.1.0-komorebi.12 — 2026-07-27

- メモリ内クリップボード履歴（最大20件、重複排除、全消去）。機密指定のクリップとパスワード欄では収集せず、プロセス終了で消去。

### v0.1.0-komorebi.13 — 2026-07-27

- 確定前の最後の文字を Backspace で消した際にひらがなが残る問題を修正。選択範囲と Unicode コードポイント単位の削除も整理。

### v0.2.0-komorebi.1 — 2026-07-27

- Open Beta 開始。起動直後にキーボードが沈み OS 操作領域と干渉する問題を、Inset の先取りで修正。

### v0.2.0-komorebi.2 — 2026-07-27

- 「了解です」のような自然な全体変換を上位へ。助詞・語尾だけカタカナの混在予測を最後尾へ。キー操作のバイブ設定を追加。

### v0.2.0-komorebi.3 — 2026-07-27

### v0.2.0-komorebi.4 — 2026-07-27

### v0.2.0-komorebi.5 — 2026-07-27

### v0.2.0-komorebi.6 — 2026-07-28

### v0.2.0-komorebi.7 — 2026-07-28

### v0.3.0-rc.44-dev — 2026-11-06

- 画像・動画・音楽・ドキュメントの共有に対応。AES-GCM、宣言サイズ、SHA-256 を検証し、受信ファイル名をサニタイズする。

- Wi-Fi Direct は実機2台での検証が未実施。Android 13 以降は近接端末、Android 12 以下は位置情報の権限を Wi-Fi Direct の検出だけに使う。

### v0.3.0-rc.45-dev — 2026-11-06

## この歴史の読み方

- **急増期**: `0.1.0-komorebi.5`〜`13` と `0.2.0-komorebi.1`〜`10` は1〜2日で19版。土台となる機能と安定化を一気に固めた。
- **空白期**: `rc.1`（8月）から `rc.4`（11月）まで公開が無く、`rc.5`〜`rc.20` は欠番。上流統合と内部作業の期間。
- **成熟期**: `rc.21`〜`rc.49` は4日で29版。AI 校正、辞書、移行、運用が一気に揃った。

> [!NOTE]
> 版番号は `versionCode` が1ずつ増えます（rc.2=26、rc.23=47、rc.35=59、rc.36=60）。`rc.2`・`rc.3` を含めると連番の整合が取れ、`rc.5`〜`rc.20` は採番されずに飛んでいることが分かります。
