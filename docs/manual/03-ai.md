# AI 機能

Komorebi IME の AI はすべて**端末内**で動きます。入力や文章を外部へ送信しません。モデルは使う人だけが明示的に取得します。

| 機能 | 何をする | モデル | 対応 CPU |
| --- | --- | --- | --- |
| zenzai-plus | 日本語の変換候補を生成し先頭に表示 | `zenzai-plus-ft-f16.gguf`（約 183 MiB、CC BY-SA 4.0） | 現在 `arm64-v8a` |
| Karukan | 軽量なニューラル変換。フォールバックにも使用 | 約 32 MB | 現在 `arm64-v8a` |
| AI 文章校正 | 選択文／直前 600 文字を校正 | Qwen3.5 0.8B / Qwen3 1.7B / Gemma 4 E2B | `arm64-v8a` |
| 文体補正 | 敬語・簡潔・自然などへ書き換え | モデル不要（ルールベース） | 全 ABI |

> [!IMPORTANT]
> **変換の AI と文章校正の AI は別物**です。モデルも設定も別々に管理されます。文体補正はモデルを使わず、定型表現・活用辞書・文末解析で端末内処理します。

## zenzai-plus

「変換エンジン・辞書」で有効にすると、`zenzai-plus-ft-f16.gguf` で日本語の変換候補を生成し、先頭に表示します。候補をタップするか、生成後に確定キーを押すと確定します。初期値は OFF です。

| 項目 | 内容 |
| --- | --- |
| 取得先 | [soichi1208/zenzai-plus](https://huggingface.co/soichi1208/zenzai-plus)（Hugging Face） |
| サイズ・SHA-256 | 192,132,704 bytes / `928fc0f3…7ec8f4` |
| 動作場所 | 端末内 CPU |
| Mozc との関係 | Mozc がある場合は文節区切り・候補操作に Mozc を使い、全文候補も併用 |
| 無効時 | モデルを解放し Mozc だけで変換 |

推論は専用ワーカーで行い、入力が進むと古い推論を中止します。パスワード欄、英数・数字面ではモデルを使いません。読み込み中や失敗時でも、かな入力とユーザー辞書の候補は利用できます。

### TTT（入力からの学習）

確定した読み・直前文脈・選んだ表記を使い、2 秒待ってから端末内で TTT（重み学習）を実行します。

| 設定 | 挙動 |
| --- | --- |
| 入力からの自動学習 オン | 確定ごとに学習。同じ読みの修正はまとめて反映 |
| 入力からの自動学習 オフ | 未処理の学習を取り消し（進行中の処理は完了することがある） |
| ユーザー辞書を学習 | 登録語を明示的に学習（最大 32 ステップ） |

学習しない条件: パスワード欄、シークレットモード、学習禁止フラグのある入力欄、クリップボードから貼った本文。学習状態は Keystore で暗号化して保存し、再起動・OFF/ON 後も復元します。

> [!NOTE]
> モデルの更新は Java ヒープを圧迫しないよう 1 MB ごとに認証し、最終版は `llama_ttt_export_version` / `llama_ttt_import_version` で推論側へ渡します。学習中に推論側の重みは変わりません。

## Karukan

文脈を考慮する軽量なニューラル変換です。モデルは約 32 MB で、明示操作で取得します。

| 変換エンジン設定 | 動き |
| --- | --- |
| 自動（既定） | zenzai が無効・利用不可・候補なしのとき、入力停止後に Karukan 候補を生成 |
| Karukan | AI 有効時にも候補を生成し、変換キーでも利用 |
| Mozc | Karukan を使わない |

モデル未導入・非対応 CPU・読み込み失敗時は Mozc へ安全にフォールバックします。パスワード欄・シークレットモード・アプリ別の AI 禁止設定では呼び出しません。

## AI 文章校正

ツールメニューの「AI 文章校正」から、キーボードの代わりに画面下部の小窓で開きます。背後の入力欄を見ながら操作できます。

| できること | 内容 |
| --- | --- |
| 対象 | 選択した文章、またはカーソル直前の最大 600 文字 |
| 校正の種類 | 誤字・文法を直す／丁寧にする／簡潔にする／自然な文章にする／自由に指示する |
| 結果の確認 | 元の文章との差分（色付きが変更箇所）で確認してから適用 |
| 適用 | 「適用／適用しない／コピー」 |
| 手入力 | 文章を取得できなくても空欄から入力して校正可 |

無効な場面: パスワード欄、学習禁止（`IME_FLAG_NO_PERSONALIZED_LEARNING`）を要求する入力欄。

| モデル | 目安 | 推奨条件 |
| --- | --- | --- |
| Qwen3.5 0.8B | 約 533 MB | 空きメモリ 3500 MiB 未満のとき推奨 |
| Qwen3 1.7B | 約 1.11 GB | 空きメモリ 3500 MiB 以上・空き容量 1600 MiB 以上で推奨 |
| Gemma 4 E2B | 約 3.11 GB | 大きいが任意で選択可 |

> [!WARNING]
> 品質は保証しません。小さいモデルは指示に従わない・意味を変える場合があります。**必ず差分を確認してから適用**してください。生成後に元の文章や指示を変えると、その結果は古いものとして扱われ、適用できません。

### 結果の保護（誤字・文法）

「誤字・文法を直す」では、生成結果をそのまま出さず、元の本文との差分から修正を組み立てます。空白・改行・全半角だけの変更は採用せず、URL・メール・バッククォート内のコード・数値・漢字名に付いた仮名の読みを含む変更を抑止します。保護は検出できた範囲に限られ、意味の正しさを判定するものではありません。

## 文体補正

入力中の未確定文字、またはカーソル直前の文章を、端末内だけで「堅い敬語／緩い敬語／ノーマル敬語／ゆるく／ふつう」へ変換します。「原文」は文章を書き換えません。

- 外部 AI サービスへ送信しません。
- 定型表現の最長一致、活用辞書、文末・接続節の解析、主語に応じた尊敬語／謙譲語の選択を多段で行います。
- 引用文、URL、メールアドレス、インラインコード、コードブロックを保護し、その周囲だけを補正します。
- 辞書にない活用は無理に推測せず、原文を保ちます。

## モデルの管理

モデルはすべて「変換エンジン・辞書」から取得・削除・選択できます。一度取得すれば、利用時はネットワークへ文章を送信しません。モデルはバックアップ対象外の領域に保存されます（[データの移行](07-iten.md) を参照）。


## どれを選ぶ？

追加取得をしなくても標準のMozc変換を利用できます。変換候補を増やしたい場合は「変換エンジン・辞書」のAI変換を、入力した文章の誤りを直したい場合は「AI文章校正」のモデルを選びます。モデルごとにダウンロード容量・端末への対応が異なります。選択画面で確認してから取得してください。

## 翻訳・手書き・画像の文字読み取り

- 翻訳する文章を選択してからツールの「翻訳」を開きます。原文と訳文を確認し、置き換えを押します。翻訳には [Google 翻訳](https://cloud.google.com/translate) を使います。初回は Wi-Fi で約30 MB／言語のモデルを取得し、取得後はオフラインで利用できます。翻訳画面から言語モデルを削除できます。
- 「手書き入力」では指やペンで書き、読み取り候補を選択します。初回に日本語モデルを取得します。
- 「画像から文字」では選んだ写真だけを処理します。結果は入力する前に編集できます。
- 入力先が変わった場合は結果を挿入しません。入力内容は端末内で処理します。[Google ML Kit の診断について](https://developers.google.com/ml-kit/terms)。
