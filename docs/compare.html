Komorebi IME は、入力した文字を端末の外へ送りません。変換も、AI も、辞書も、ぜんぶ端末の中。Gboard や Simeji との違いは、そこに尽きます。

権限は用途別です。INTERNET はモデル・追加辞書の取得と更新確認、NFC は Meets Beam と NFC 移行、Wi-Fi Direct は ACCESS_WIFI_STATE / CHANGE_WIFI_STATE / NEARBY_WIFI_DEVICES、Android 12 以下では位置情報（Wi-Fi Direct の端末検出のみ）を使います。Android 13 以降でも Wi-Fi Direct の検出には端末の位置情報モードをオンにする必要があります。位置の記録・外部送信は行いません。広告・解析用の権限はありません。

ハイライト

違いは、4つにまとまります。

どれも「機能が多い」という話ではありません。入力がどこへ行くか、という話です。

送信

クラウドへ行く道が、ない。

Mozc を端末に組み込み、変換はオフラインで実行します。AI も端末内。外部通信には、モデル・辞書の取得、絵文字データの更新確認、設定で停止できる GitHub 更新確認があります。Meets Beam の転送は NFC と Wi-Fi Direct の端末間だけで、クラウドを経由しません。

収益

入力は、広告の材料にしない。

広告SDKも解析SDKも入れていません。無料で使えますが、入力を見返りに売る作りにはしていません。

検証

説明ではなく、コードで。

Apache-2.0 でソースを公開。Mozc への変更もパッチで公開しています。「送っていません」を信じる必要はありません。

保存

辞書も学習も、暗号化して手元に。

ユーザー辞書は TSV で入出力。学習履歴・辞書・優先候補は Android Keystore の鍵で暗号化。クラウドバックアップは無効です。

理由

乗り換える理由は、4つ。

01

入力した文字を、外に出さない

変換は Mozc を端末に組み込んで実行します。AI 変換も AI 文章校正も端末内。外部通信には、モデルや追加辞書の取得、絵文字データの更新確認、初期状態でオンの GitHub 更新確認があります。更新自動確認は設定で停止できます。Meets Beam のファイル・辞書転送は NFC と Wi-Fi Direct の端末間通信だけで、クラウドを経由しません。入力・文脈・辞書・学習履歴は外部へ送りません。

02

入力は、広告の材料にしない

広告SDKも解析SDKも組み込んでいません。無料で使えますが、入力を見返りに広告主へ売る作りにはしていません。これは会社の善意ではなく、そういう作りにしていない、という話です。

03

「送っていません」を、確かめられる

ソースコードを公開しています（Apache-2.0）。Mozc への変更もパッチとして公開しています。会社の説明を信じる必要はありません。コードと権限を見れば済みます。

04

辞書も学習も、自分のもの

ユーザー辞書は TSV で入出力できます。学習履歴・辞書・優先候補は Android Keystore の鍵で暗号化して保存。クラウドバックアップは無効です。機種変更はファイルか NFC で移せます。

前例

2013年、Simeji で起きたこと。

「OFFにしているのに送られていた」。これは作り話ではなく、実際に起きた事故です。

  1. 2013年12月26日 セキュリティ会社が指摘

    Simeji が入力内容を無断で外部に送っている、と公表。

  2. 同日 「プログラムの不具合」と説明

    記録をOFFにしていても、一部が送られていた。

  3. 同日 8か月間続いていた

    不具合は2013年3月の版から混入。同じ会社のパソコン用ソフトでも同時に問題が起きていた。

  4. 2013年12月27日 修正版で、初期設定を変更

    「クラウド変換」を初期設定でOFFに。問題の一部は不具合ではなく、最初からONにしていた設定だった。

FAQ

よくある質問。

Gboard より安全ですか？

「安全」を「入力が外に出ないことを自分で確かめられる」と定義するなら、はい。Gboard は検索・利用統計・音声を Google に送ると自社ヘルプに書いています。Komorebi IME は入力も統計も送らず、コードも公開しています。

入力は本当に送られませんか？

外部サーバーへ送りません。要求する権限は、任意取得・更新確認用の INTERNET、接続状態確認用 ACCESS_NETWORK_STATE、再起動後の更新確認用 RECEIVE_BOOT_COMPLETED、通知用 POST_NOTIFICATIONS、Meets Beam・NFC移行用の NFC、Wi-Fi Direct 用の Wi-Fi/近接端末権限、Android 12 以下に限り Wi-Fi Direct 検出用の位置情報です。位置の記録・送信はしません。Meets Beam は端末間 P2P だけで、クラウドを経由しません。疑うなら、コードを読むか通信を自分で観測してください。それができるのが、ソース公開の意味です。

オフラインで使えますか？

使えます。Mozc を端末に組み込んでいるので、変換に通信は不要です。AI 機能を使う場合だけ、モデルを一度取得します。取得後の推論はオフラインです。

AI はクラウドですか？

いいえ。AI 変換（zenzai-plus / Karukan）も AI 文章校正（Qwen / Gemma）も端末内で動きます。文章を外部へ送りません。

無料ですか？広告は入りますか？

無料です。広告は表示しません。広告SDK・解析SDK・クラッシュレポートSDKも組み込んでいません。

辞書はほかの IME から移せますか？

Mozc / Google 日本語入力互換の TSV をそのまま取り込めます。書き出しもできます。取り込みは現在の辞書を置き換えるので、先に書き出しておいてください。

音声入力や翻訳はできますか？

できません。ここは大手に負けています（比較表の「—」）。必要なら、音声入力は OS や別アプリに任せてください。Komorebi IME は日本語入力と変換に絞っています。

多言語は？

日本語が中心です。英語の入力はできますが、多言語の切り替えは大手ほど得意ではありません。

何が劣っていますか？

機能の数、多言語、音声、翻訳、そして実績です。まだ Release Candidate で、AI 機能は一部の CPU だけ、実機での確認が続いている項目もあります。便利さの合計では負けます。

元に戻せますか？

戻せます。Android の設定でキーボードを切り替えるだけです。アンインストールすれば、端末内のデータも削除されます。
