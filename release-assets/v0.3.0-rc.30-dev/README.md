`0.3.0-rc.30-dev` は候補の行数設定と読みやすさを修正するテスト版です。ユニバーサル debug 署名 APK（`me.zssu.ime.debug`、versionCode 54）で、正式署名版ではありません。

## rc.29-dev からの修正

- 固定3列・6件のグリッドを廃止し、外観設定の「候補の行数」（1行／2行）を変換中にも反映します。
- 候補の標準文字サイズを20spへ拡大。文字サイズの倍率と端末の文字サイズを反映し、文字の実測幅からページを組み立てます。長い候補は広く表示し、幅が狭ければ表示件数を減らします。
- 候補番号・件数専用ヘッダー・前後ページのボタン群を削除。通常は候補と右端の展開ボタンを表示します。
- 候補欄の左右スワイプで別ページへ移動。変換キーは実際に表示中の候補IDだけを巡回します。未計測・古いID・ツール表示中などには隠れた候補へ進めません。
- 展開した一覧は、番号なし・1列の大きな文字へ変更。右上の上向きボタンで戻れます。
- 文節の一覧と4つの操作ボタンを通常表示から外し、候補一覧の「文節を調整」から必要なときに開く形に変更しました。

## 検証と制約

アプリ207件・Karukan 2件の単体テスト、debug/release lint、通常APK/AABとABI別APKのビルド、APK内容・16 KB配置・JNI名保持を確認しています。ページ分割は、複数の幅・文字幅・1行／2行で候補の重複・欠落や行のはみ出しがないことをテストしています。

実機・エミュレータでの表示とタッチ操作、Android各世代の入力互換性は未確認です。特に文字サイズ変更、片手・横画面、左右スワイプ、一覧からの復帰、文節調整は実機での確認が必要です。

操作の詳細は[変換UI](https://github.com/zenskypj/Komorebi-IME/blob/v0.3.0-rc.30-dev/docs/conversion-ui.md)を参照してください。
