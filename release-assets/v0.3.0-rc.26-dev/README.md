`0.3.0-rc.26-dev` の修正版テスト APK です。**ユニバーサル debug 署名版**（`me.zssu.ime.debug`、versionCode 50）です。実機での操作確認は未実施で、正式署名版ではありません。

## rc.25-dev からの修正

- ツールメニューを縦スクロール可能にし、10件目以降のツールにも到達できるようにしました。編集画面にも適用しています。
- 標準の上部表示を「クリップボード → 絵文字 → 片手モード → AI文章校正 → 設定」に変更。独自の並べ替え設定は保持し、編集画面の「標準順に戻す」で初期状態へ戻せます。
- 変換の一回目は先頭候補を選択し、二回目以降に次の候補へ進むよう修正。前処理ですでに変換が始まった場合の二重実行も抑制します。
- Karukanの明示変換でも前処理の重複を取り除きました。
- 最初の押下、二回目の押下、前処理での変換開始、前処理で確定した文章の保持について回帰テストを追加しました。

- 「入力の使い方」を専用の設定項目へ移動。フリックを試せる図、文節の操作イメージ、実際の入力欄を使う練習、ツールの説明を4章に整理しました。

- 変換エンジンに「自動」を追加。導入済みKarukanを、AI無効・利用不可・候補なし・応答待ち時の自動候補生成に使用します。明示的なKarukan選択ではAI有効時も併用できます。機密欄・アプリ別禁止設定・モデル未導入時は除外し、古い要求は破棄します。

アプリ183件・Karukan 2件の単体テスト、debug/release lint、APK/AAB・ABI別ビルド、バージョン・16 KB配置・ネイティブライブラリ・法務文書・JNI名保持を確認済みです。Android各世代、片手表示、メニューのスクロール、各エンジンでの実際の操作感は実機確認待ちです。
