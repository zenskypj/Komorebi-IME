# 0.3.0-rc.21-dev テスト用 APK

ユニバーサル debug 署名版（`me.zssu.ime.debug`、versionCode 45、versionName `0.3.0-rc.21-dev`）。
**正式署名版ではありません。** 実機での操作確認は未実施です。ネイティブライブラリは
GitHub のファイルサイズ上限に収めるため圧縮しています（`-PcompressNativeForTest=true`）。

## rc.20-dev からの変更

- **AI 文章校正を小窓化**: キーボード上部のツールから開くと、画面下部の小窓として表示する。
  取得した文章を校正前に編集・追記でき、文章を取得できない場合は空欄から手入力できる。
- **書き換えの種類を選択**: 誤字・文法を直す / 丁寧にする / 簡潔にする / 自然な文章にする /
  自由に指示する（自由指示は本文と別に入力、200文字以内）。
- **結果の確認と選択**: 校正結果を元の文章との差分（色付きが変更箇所）で表示し、
  「適用」「適用しない」「コピー」を選べる。生成後に元の文章や指示を変えると、
  その結果は古いものとして扱い適用できない。
- **反映できないアプリへの対応**: 校正画面から戻ったときに入力欄と対象文章が変わっていないかを
  `getSelectedText()` / `getExtractedText()` / `getSurroundingText()`（Android 12 以降）で確認してから
  置換する。安全に確認できない場合は上書きせずコピーを案内する。`InputConnection` が例外を返しても
  IME は落ちない。
- **モデルの入口と案内**: 設定に「AI 文章校正モデル」を追加。モデル未導入・端末非対応の理由を表示。
  zenzai-plus も利用できない理由を表示し、Qwen3 校正用モデルとは別物であることを明記。
- **候補表示中のメニューボタン**: 候補が表示されている間も、横スクロール領域の外にある
  ツールメニューボタンを常に表示する。メニューを閉じると直前の変換候補表示に戻る。
- **変換キーの初回押下**: かな面で変換キーを押すと、初回から変換候補へ進む（HENKAN→SPACE の順で試行）。

## 実機での未確認項目

- 校正小窓の表示位置・操作のしやすさ
- 各アプリ（WebView を含む）の入力欄への反映
- 変換キー初回挙動、候補表示中のメニュー操作

## インストール

```
adb install -r Komorebi-IME-0.3.0-rc.21-dev-universal-debug.apk
```

applicationId は `me.zssu.ime.debug` です。正式版 `me.zssu.ime` とは別枠なので共存できます。
