`0.3.0-rc.27-dev` は文節操作中のカーソル同期を修正するテスト版です。ユニバーサル debug 署名 APK（`me.zssu.ime.debug`、versionCode 51）で、正式署名版ではありません。実機での再現・操作確認は未実施です。

## rc.26-dev からの修正

- 変換中は入力先のカーソルを未確定範囲の末尾に保ち、文節の選択をハイライトと文節バーで示します。文節を移動・縮小・拡大するたびに入力先の絶対カーソル位置を動かす処理を除去しました。
- 書き換え直後の古い選択位置から未確定範囲を逆算する処理を廃止。未変換の読みを途中編集する場合は、書き換え前の実際の composing span と本文が一致した場合だけカーソルを戻します。確認できない入力欄では推測した位置へ移動しません。
- 変換範囲内の遅延したカーソル通知によって変換状態を解除しないよう修正。実際の範囲外移動・範囲選択・未確定範囲の削除は引き続き扱います。
- 変換状態が解除されたときに文節操作バーも非表示にし、古い操作UIが残る経路を修正。
- 文節長の反復変更、古い範囲情報、部分抽出、補助平面文字、範囲外通知を回帰テストに追加。
