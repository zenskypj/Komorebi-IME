# 0.3.0-rc.22-dev テスト用 APK

ユニバーサル debug 署名版（`me.zssu.ime.debug`、versionCode 46、versionName `0.3.0-rc.22-dev`）。
**正式署名版ではありません。** 実機での操作確認は未実施です。ネイティブライブラリは
GitHub のファイルサイズ上限に収めるため圧縮しています（`-PcompressNativeForTest=true`）。

## rc.21-dev からの変更

- **校正モデルを刷新**: 軽量側を **Qwen3.5 0.8B**（`unsloth/Qwen3.5-0.8B-GGUF`、Q4_K_M、約533 MB）に、
  高精度側は現行の **Qwen3 1.7B**（`unsloth/Qwen3-1.7B-GGUF`、Q4_K_M、約1.11 GB）を維持。
  どちらも Apache-2.0 / Unsloth 量子化、リビジョン固定・SHA-256 検証つき。
- **校正モデル管理UIを作り直し**: 「AI 文章校正モデル」を独立した全画面画面に再建。
  2モデルの取得・中断・削除・選択、進捗、おすすめ表示、ライセンス表記を1か所にまとめた。
  （rc.21 の小窓内モデルUIはレイアウト崩れがあったため廃止。）
- 校正の小窓（レビュー画面）はレイアウト方式を修正し、画面下部のパネルとして安定表示。
  モデルの準備状況を表示し、「モデルを管理」から上記画面へ移動する。

rc.21-dev の内容（校正小窓・種類選択・自由指示・差分・適用/適用しない/コピー・古い結果の適用防止、
反映時の入力欄照合、変換キー初回で候補、候補表示中のメニューボタン）も含みます。

## 実機での未確認項目

- 校正小窓の表示位置・操作のしやすさ
- 校正モデル管理画面の操作とダウンロード
- 各アプリ（WebView を含む）の入力欄への反映
- 変換キー初回挙動、候補表示中のメニュー操作

## インストール

```
adb install -r Komorebi-IME-0.3.0-rc.22-dev-universal-debug.apk
```

applicationId は `me.zssu.ime.debug` です。正式版 `me.zssu.ime` とは別枠なので共存できます。
