`0.3.0-rc.32-dev` はキーボード操作・予測順位・学習と次文節への移行を改善するテスト版です。ユニバーサル debug 署名 APK（`me.zssu.ime.debug`、versionCode 56）で、正式署名版ではありません。

## rc.31-dev からの変更

- ツールメニューへ「キーボードの高さ」を追加。入力中のキーボードを見ながら調整し、保存・取消・標準へ戻す操作ができます。アプリ別プロファイルが有効な場合は、そのアプリの高さを保存します。
- 日本語のリアルタイム順位調整が `SUGGESTION` だけに適用され、実際のmixed conversionの `PREDICTION` を見逃していた問題を修正。日本語QWERTYにも適用します。
- 助詞1文字で終わる、または助詞から始まる候補でも、入力した読みとの対応を確認して、文字種だけの候補や誤入力補正より優先。より長い別の読みの予測を同じ変換として扱いません。ネイティブの学習履歴も順位へ反映します。
- AI候補の先頭表示・自動選択は維持します。確定時には表示中の先頭候補と確定先を一致させます。
- QWERTYのスペースを左右フリックしたまま長押しすると連続カーソル移動。中心付近で停止し、離れるほど速くなりますが速度上限を設けます。処理が遅れた後のまとめ移動を防ぎ、反転・指離し・キーボード非表示時に停止します。
- かなフリックの長押し中の「カーソル」表示をキー幅・高さへ収め、狭い場合は2行に表示。長押し中にフリックガイドが重ならないようにしました。
- AI自動学習では、確定結果の実際の読みを使用し、文脈あり／なしの例と、確認できる文節・複合語を学びます。語の読みを推測で作らず、送り仮名や名前の一部を助詞として切り落としません。文字種を変えただけの結果をTTT再学習から除外します。既存の学習結果は保持し、今後の確定分に適用します。
- 前の文節を確定して読みが残ったら、次の文節の候補を自動で開いて先頭候補を選択。2文節目以降は変換キーを押し直す必要がありません。最初の文節の二段階操作は維持します。

## 検証と制約

アプリ236件・Karukan 2件の単体テスト、debug/release lint、通常APK/AAB・ABI別APK、APK内容・16 KB配置・JNI名保持を確認しています。助詞を含む順位、長い別読みの抑止、AI先頭の維持、学習例の共通化と誤分割の抑止、距離に応じた連続移動・反転・停止、次文節への移行条件をテストしました。

実機・エミュレータでの表示、タッチ操作、連続入力、TTT学習後の精度・速度・発熱は未確認です。順位改善は利用可能な候補の並べ替えで、候補にない正解を生成する保証はありません。AI候補の品質そのものの保証ではありません。学習は既存のON/OFF・機密欄での抑止・暗号化保存・リセットを引き継ぎます。

詳細は[変換とキーボード操作](https://github.com/zenskypj/Komorebi-IME/blob/v0.3.0-rc.32-dev/docs/conversion-ui.md)を参照してください。
