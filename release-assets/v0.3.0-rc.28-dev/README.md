`0.3.0-rc.28-dev` はAI文章校正の `/no_think` 混入を修正するテスト版です。ユニバーサル debug 署名 APK（`me.zssu.ime.debug`、versionCode 52）で、正式署名版ではありません。

## rc.27-dev からの修正

- 校正対象の本文へ `/no_think` を付加する処理を廃止。思考出力の抑制用プレフィックスは assistant ターン側に維持します。
- 元の本文にない `/no_think`・`/think` が結果に混入した場合は、その結果を破棄し、適用・コピーへ渡しません。
- 制御文字列そのものを説明する原文を勝手に削除しないよう、原文に含まれる回数と区別して検証します。
- 人名と読みの末尾への混入、先頭・空白なし・大文字での混入、元からあるコマンドの保持、プロンプトへの付加禁止を回帰テストに追加。

## 検証と制約

アプリ192件・Karukan 2件の単体テスト、debug/release lint、APK/AAB・ABI別ビルド、APK内容・16 KB配置・JNI名保持を確認済みです。
モデルの実機推論と校正品質、Android各世代での操作確認は未実施です。人名・括弧などに対する不要な書き換えも、適用前に差分で確認してください。
