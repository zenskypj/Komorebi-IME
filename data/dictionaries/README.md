# 同梱固有名詞辞書

利用者が2026-11-05に提供したJSONLを、既存の同梱`proper-nouns.txt`へ統合する。
任意取得のネット辞書・追加システム辞書パックやJSON意味辞書としては登録しない。
APK内に入り、従来の「有名固有名詞」スイッチと同じMozc取り込み先で使用する。

- `proper-nouns-base.tsv`: 統合前の原本532行（読み・表記で517語）。従来のCC0表示を保持。
- `proper-nouns-extra.jsonl`: 提供された4,468行をバイト単位で保持。
- 原ファイル名: `c5a94a1f7e7b4c51aa8e36a024c50004.jsonl`。
- SHA-256: `1bef2f82638be8e7e17af961319170e7bbbc23bcb623f97d740c816401f7746d`。
- 追加データに既存原本のCC0を自動適用しない。利用者の組み込み依頼に基づく追加として出典を保持する。

既存側の重複15行と、追加分との重複106語を整理し、4,879語にした。
純増4,362語。94語は一般の固有名詞から、人名・地名・組織の具体的品詞へ更新した。

| JSONLの品詞 | 既存Mozc取り込み用ラベル | 提供件数 |
| --- | --- | --- |
| 名詞,固有名詞,地名 | 地名 | 809 |
| 名詞,固有名詞,人名 | 人名 | 1,408 |
| 名詞,固有名詞,組織 | 組織 | 751 |
| 名詞,固有名詞,一般 | 固有名詞 | 1,500 |

読みをNFKC・ひらがなに正規化し、表記はNFCで保持する。読み・表記の組で重複整理し、
従来の具体的品詞は維持、従来の一般的な固有名詞には追加分の具体的品詞を反映する。

原本の`cost`（2,000〜7,000）は保存するが、既存の同梱辞書経路は
`読み<TAB>表記<TAB>品詞`のTSV取り込みであり、語ごとの順位コストを指定できない。
この値をMozcへ適用したとは扱わない。nativeライブラリや標準`mozc.data`は再生成しない。

```bash
python3 scripts/merge_bundled_proper_nouns.py
```

上記でAPK同梱TSVと`proper-nouns-merge.json`を決定的に再生成する。
次回追加時も原本を残し、生成済みTSVを直接手修正しない。
アプリ更新時は従来と同じ辞書名で差し替え、個人辞書・学習履歴は維持する。
固有名詞辞書を無効にしている場合は、アプリ更新後も無効を尊重する。
